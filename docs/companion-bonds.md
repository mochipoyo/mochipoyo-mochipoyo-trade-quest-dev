## 1. 方針

- **仲間は主人公のためだけにいる人ではない。** 一人ひとりに好物・趣味・癖・弱点・笑える一面を持たせました。行動と会話で伝え、説明の台詞には頼りません。
- 悲しい過去を全員に足すことはしていません。お茶・鍋・パン屋・水切り・丼・散歩・寝相など、小さな思い出を中心にしています。
- **主人公の台詞は選択肢で表します。**
  - 台詞に一人称（僕・私・俺など）を使いません。
  - 「〜だぜ」「〜わ」などの性別を感じさせる語尾も使いません（テストで点検）。
  - 気持ちを一つに決めつけません。「話さない」「笑ってごまかす」も選べます。
- **選択の記憶は、小さな選択が後から戻ってくる形にしました。** 大きな分岐はありません。
  - 例：リーナと話した焼き菓子が第3話と記念品とエンディングに出る。
  - 例：セリスと決めた光の色が、第3話のランプの色になる。
  - 例：イーリスと座った席が、みんなの地図に描かれる。
  - 例：M と決めた最初の記録が PC のフォルダに入る。
  - 例：ポン太の散歩で見つけた笛のお礼のリボンが、記念品になる。
- **教訓を押し付けません。** トレードの話は、ルシア × M の「入らない勇気」の一場面に絞りました。人物どうしのやり取りとして描いています。

## 3. 絆の段階（好感度の数値ではない）

| 段階 | 意味 | 何で進むか |
|---|---|---|
| 0 | 加入直後 | 加入した |
| 1 | 日常の一面を知る | 第1話を見た |
| 2 | 本人と重要な出来事を経験する | 第2話を見た（多くは既存の個人クエストのあと） |
| 3 | 本人の変化を見届ける | 第3話を見た |

- 段階の呼び名は人ごとに違います。例：リーナは「旅の仲間 → お茶を淹れ合う仲 → 支え合う仲間 → 互いに頼れる仲間」。
- 恋愛を強いる仕組み、「数値が高いから正解」という仕組みはありません。
- 個人の話を見ても見なくても、戦力は上下しません。記念品は持ち物ではなく、手帳の記録だけです。
- 話の ID は「人_番号」（例 `lina_2`）、関係の話は「pair_人_人」で固定です。見た記録は `d.bonds.seen[ID]` に入ります。

### 解放の条件（くわしくは `docs/companion-bonds-tables.md`）

- 第1話は加入していれば見られます（主人公の第1話は第4章の達成後）。
- 第2話・第3話は、前の話を見ていることに加えて、既存の個人クエストの達成、または本編の章の達成が条件です。
- 一部の話は場所が決まっています（ガルド第2・3話＝ヴェルム、イーリス第2・3話＝アルナ、ソフィア第3話＝鐘都など）。条件を満たしていても、その地域へ行くまでは「〇〇で見られそう」と出るだけです。
- **関係の話は、二人とも加入しているときだけ見られます。** どちらかが未加入なら、その組だけ保留です。関係の話を、本編や個人の話の条件にはしていません（テストで確認）。

## 4. 選択の記憶・先送り・二度起きない

| 記録（`d.bonds`） | 中身 |
|---|---|
| `seen` | 見た話・関係の話（ID → 日時） |
| `later` | 「今日はやめておく」で先送りした話（取り逃がさない。次は「この前は途中だった」の一言から始まる） |
| `mem` | 小さな選択の記憶（焼き菓子・光の色・座った席・最初の記録など。後の話・会話・記念品・エンディングで戻ってくる） |
| `last`・`hist` | 仲間ごとの「最後に選んだこと」と履歴（手帳と、話しかけたときの欄に出る） |
| `keep` | 記念品（持ち物ではない記録） |
| `chat` | 日常会話の順番 |
| `heard` | 交わした日常会話（v9.4.1。同じ話は1つにまとめ、1人 40 件まで。手帳で読み返せる） |
| `post` | クリア後の「旅のあとの話」を聞いた日時（v9.4.1） |
| `camp` | テントを張った場所（少しのあいだ、そこで話せる） |

- 話を最後まで見たときに `seen` に入ります。見た話は「新しい話」に二度と出ません。
- 「今日はやめておく」を選んだ話は、見たことになりません。あとでまた見られます。
- **v9.4.1：記録は、話を最後まで見たときにだけ確定します。** 途中の選択（`mem`）・最後に選んだこと（`last`・`hist`）・記念品（`keep`）は写しにためておき、最後にまとめて書きます。
  - 途中でページを閉じた・エラーになった・「今日はやめておく」を選んだ、のどれでも、先送りの回数のほかは何も書きません。同じ話を最初からもう一度見られます（進行不能にならない）。
  - 同時に二つの話は始まりません（`Bonds.playing` の間は、二つ目の再生も「仲間と話す」もすぐ戻る）。

## 5. 画面

### 「仲間と話す」（メニュー →［パーティ］）

- **話せる場所**
  - 町・村・建物の中（宿屋・酒場を含む）・野営地で話せます。
  - フィールドやダンジョンでは、テントを張った直後、その場所で話せます（40歩まで）。
  - プロローグの最中は話せません（本編に割り込まない）。
- **一覧**
  - 加入済みの仲間（戦闘メンバーも待機メンバーも）、ポン太、主人公（「自分のこと」）が並びます。
  - v9.4.1：並びは**加入した順**です（ポン太は仲間のあと、主人公は最後）。新しい話がある人には小さな印（★）だけを付けます。
  - 右の欄に、立ち絵・絆・思い出 n／3話・新しい話（あり／なし／〇〇で見られそう）・最後に選んだこと、が出ます。
- **選ぶと**：「話す（話題の名前）」「新しい話「題」」「〇〇と一緒に「題」」から選べます（取り残しの回収があれば、いちばん上に出ます。8 章）。
  - v9.4.1：話の中の選択肢は、「今日はやめておく」がある問いだけキャンセル＝先送りです。ほかの問いはキャンセルしても閉じません（既存の `Win.choice` の `cancel:false`）。長い選択肢は折り返します。
  - 一度に全部の会話を出すことはしません。日常会話は、1回に1つの話題だけです。
  - 話題は、いつもの話・食べ物と趣味・この辺りの話・最近の戦い・ほかの仲間・旅のあと（クリア後）を順に回します。地域・加入状況・見た関係の話・クリアの有無によって、出る話題が変わります。
  - 関係の話を見たあとは、その二人の「ほかの仲間の話」の先頭が変わります。
- 話はメニューを閉じてから再生します（3D のカメラが見えるように）。
- **宿屋・酒場から**
  - 宿に泊まったあと・テントを張ったあと、新しい話がある仲間がいれば**小さなトースト**で一言だけ知らせます（v9.4.1。選択の窓は出しません＝強制的なポップアップをしない）。
  - 酒場の編成画面に［仲間と話す］ボタンを付けました。

### 「仲間の思い出」（メニュー →［パーティ］）

- 18人分の記録です。中身は次のとおりです。
  - 顔・名前・人物紹介・加入した場所・好きなもの・性格・絆・個人の話の達成（n／3）
  - 思い出（見ていない話は「？？？」と自然なヒント、または「〇〇で見られそう」）
  - 主人公と選んだことの履歴
  - ほかの仲間との関係（見ていない組は「？？？」）
  - 記念品
  - 最近交わした会話（v9.4.1。再生の一覧の「交わした会話を読み返す」で全部読めます）・クリア後は「旅のあとの話」を聞いたか
- v9.4.1：並びは、加入した順 → まだ出会っていない人 → 主人公です。
- 未加入の仲間は「？？？」と、出会いのヒントだけを出します（ネタバレを避ける）。
- 見た話・関係の話は、いつでも再生できます。**再生では、記録・持ち物・経験値・フラグを一切変えません。**
  - 選択肢は、再生の中でだけ反映します。
  - テストで、再生の前後のセーブの中身が1文字も変わらないことを確かめています。ブラウザでは、ゲームの時計で進む値（遊んだ時間・時刻）を除いて比べています。

### エンディング

「仲間たちの、それから」のあとに「旅のあいだに、分け合ったもの」を足しました。3話すべてを見た仲間だけ、選択の記憶が戻ってくる一文が出ます。見ていなければ何も出ません（既存のエンディングの文は変えていません）。

## 6. 気持ち・演出（2D・3D）

- **気持ちの10種**（喜び・悲しみ・怒り・驚き・戸惑い・照れ・不安・安心・決意・親しみ）を、台詞ごとに付けています。
  - 2D・3D とも、会話の窓の立ち絵の動きで表します。例：喜び＝跳ねる、悲しみ＝沈む・暗く、照れ＝桃色の光、決意＝少し大きく。
  - 動きを減らす設定（prefers-reduced-motion）の端末では動かしません。
- **3D で使っている既存の仕組み**
  - `MTQ3D.cine`（イベント用カメラ）：話の間、主人公と話している仲間の間に寄ります。親しい話は近く（距離 8）、ふだんは 10、静かな場面は 14 です。話し手が変わるたびに向け直し、終わると元に戻します。
  - `MTQ3D.emote`：主人公のモデルにある動きだけを使います（喜び＝Victory、驚き＝Hit、決意＝Defend）。
- **3D でできないこと（未対応）**
  - 隊列に見えていない仲間（待機メンバー）とポン太は、3D のフィールドにいないため、カメラを向けられません。
  - 仲間どうしを向き合わせる、仲間の表情や手足を動かす仕組みは、既存の 3D の部品にありません。存在しない動きは呼んでいません。
  - これらは、カメラの寄り・間（`p`）・文章・2D の立ち絵の動きで表しています。

## 8. 正しい指示書の 11〜14 章への対応（v9.4.1）

### 8-1. 11A ミナの父のイベント（調べた結果と直したこと）

**確かめたこと（事実）**

- 封印区画の記録台（`js/data/islands.js`）は、ミナが**戦闘メンバーにいるときだけ**、ミナの台詞（「……読む。私が読む。」「……父さん。」）とクエスト「ミナの父」（`mina_father`）の達成が起きます。
- ミナがいないと、本編（`main_9`）だけが達成され、`mina_father_record` が立ちます。2回目からは「記録台。最後の記録係の記録は〜」の一文だけになり、**あとから達成する道がありませんでした。**
- クエスト「ミナの父」の受注も、海底都市に初めて着いたときにミナがいる場合だけです。
- 基準コミット（6b4d2a9）のゲームで、ミナを外して記録を読むと「ミナの父」が未達成のまま残ることを、実際のイベントを動かして確かめました（`docs/tools/rpg94/make_old_saves.js` → `fixtures/old_ch9_mina_absent.json`）。

**直したこと**

- 取り残しを見つけて（`mina_father_record` が立っている・ミナが加入している・「ミナの父」が未達成）、あとからミナと読めるようにしました。
  - 「仲間と話す」→ミナ →「父の記録を、ミナと読む」（町・宿などどこでも。待機中のミナでもよい）
  - 記録台を、ミナを連れて調べたとき
- 場面の文は**既存の記録の全文と、既存のミナの台詞**をそのまま使っています（新しい事実は足していません）。記録を「持ち帰った」か「残した（写しを持ち帰った）」かで、最初の一文だけ変わります。
- 最後まで見たときだけ、既存の `Events.questComplete('mina_father')` で達成します（報酬は既存のまま：素早さの指輪・経験値）。途中で止まったら何も変わらず、もう一度読めます。達成済みならもう出ません。
- **既存の支え会話**（2052年の円盤の前で主人公が「一人じゃないよ。ここにいる。」と言う場面）は変えていません。
  - ミナ第2話・回収の場面に、その文はくり返していません（テストで点検）。
  - 支え会話を見たあとなら、ミナ第2話に「……あれ、まだ効いてる。」という一言だけが出ます。
- ミナ第2話の最初の文を「記憶の図書館から戻った夜」から「父の記録を読んだ夜」に変えました。図書館以外で読んだ場合と食い違わないためです。

**同じ形の取り残し（調べた結果、ついでに回収できるようにしたもの）**

| クエスト | 取り残される条件 | 回収 |
|---|---|---|
| `seris_master`（セリスの師） | オラクル中枢 第2層で、セリスがいないまま師の記録を読む | 仲間と話す／元の場所でセリスと読む。既存のフラグ `seris_master_done` も立てる |
| `seris_origin`（師の最後の手記） | 起源の実験室で、セリスがいないまま手記を読む | 仲間と話す／元の場所でセリスと読む |

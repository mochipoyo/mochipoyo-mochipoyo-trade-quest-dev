# v8.4 3D 版：歩く／走るの切り替え

依頼（2026-11-08）：3D 版の主人公たちの歩く速さが遅いので、今の速さを「歩く」とし、特定のキーで速い「走る」に切り替えられるようにする。

## 1. 変更前の作り（確かめた事実）

| 操作 | 速さ（設定「歩く速度：はやい」＝初期値） | 動き |
|---|---|---|
| キーだけ・スティックを大きく倒す | 秒速 6.075 マス（内部の名前は RUN） | Run のクリップ（再生 1.125 倍） |
| Shift を押したまま・スティックを少し倒す | 秒速 3.038 マス（内部の名前は WALK） | Walk のクリップ |

README の操作説明は「押しっぱなしで走る・Shiftで歩く」でした。依頼どおり、上の 1 行目（いつもの速さ）を「歩く」とみなしました。

## 2. 変更後

| 操作 | 速さ | 動き |
|---|---|---|
| キーだけ（歩く。最初はこちら） | 秒速 6.075 マス（**変更前と同じ**） | 変更前と同じ |
| **R キー**（または右下の「**走る**」ボタン）で走るにする | 秒速 **9.72 マス**（歩くの 1.6 倍） | Run のクリップ（再生 1.53 倍） |
| もう一度 R／「走る」ボタン | 歩くに戻る | — |
| Shift を押したまま（歩く・走るのどちらでも） | 秒速 3.038 マス（変更前と同じ「ゆっくり歩く」） | Walk のクリップ |

- 切り替えると「走る（R キーで歩くに戻す）」などの短い通知が出る。「走る」ボタンは走るの間、金色になる。
- R で切り替えられるのは 3D の探索中だけ。会話・メニュー・必殺技のチャート（R＝振り返り）・入力欄では切り替えない。Ctrl＋R（再読み込み）はそのまま。
- 切り替えは 3D 版だけの保存 `mtq3d-run`（`on`／`off`）に覚える。再読み込みしても続く。セーブデータ・2D 版の保存には書かない。
- 馬車に乗っている間は変えない（馬車の速さのまま）。船・飛空艇（マス単位で動く乗り物）も変えない。
- 設定「歩く速度」（ふつう／はやい／とてもはやい）は、歩く・走るの両方に今までどおり掛かる（走るは：ふつう 8.64・はやい 9.72・とてもはやい 10.8 マス／秒）。
- 走るの動きの再生の速さは、速さどおり（1.8 倍）にすると足の動きがせわしないため 1.53 倍にした。その分、足は少しすべる（実機で見た目を確認してください）。
- 2D 版は変えていない（R キーは 2D 版では何もしない）。
- PC の右の欄「操作方法」に「R 走る・歩くの切り替え（3D版…）／Shift 押している間はゆっくり歩く」の行を足した（3D 版のページだけ）。README の 3D 版の操作の行も直した。

### 画面の配置の直し（スマホの横画面）
スマホの横画面で左右の余白が狭いとき、操作パネルの補助ボタンの並び（ミニマップ〜全画面）が、3D の小さいボタンの並び（走る・＋・－・3D設定）に重なっていた。
「走る」と、もとからある「＋」が隠れて押せなかったので、**重なるときだけ**補助ボタンの並びのすぐ上へ持ち上げるようにした。
PC と縦画面は、重ならないので位置は変わらない（確認：PC は y=516、縦画面は y=421 で変更前と同じ）。3D 設定を開いている間は今までの位置。

## v9.6.1 の直し：3D の戦闘が表示できず 2D になる不具合

- **症状：** 「3Dの戦闘の表示に失敗（SecurityError: Failed to execute 'getImageData' … The canvas has been tainted by cross-origin data）」が出て、3D の戦闘が 2D に切り替わった。
- **原因：** 素体の画像を CORS なしで読んでいた。githack などで画像が「別のサイト扱い」になると、キャンバスが汚れてピクセルを読めなくなる。そこで出た例外が 3D の戦闘の組み立てまで止めていた。既存の 4 方向の絵（PartyDirections）・readable.js は CORS で読んでいたが、新しい部品だけ違っていた。
- **直したこと：**
  1. 素体を `crossOrigin = 'anonymous'` で読む。
  2. 読めても汚れている画像は使わない。
  3. 合成の失敗で例外を投げない。3D の戦闘・メニュー・2D の欄は、本人の元の絵のまま続ける。
  4. 素体・マスクの URL に中身のハッシュ（`?v=`）を付けて、古い画像がキャッシュから出ないようにした。
- **確かめ方：** 素体の画像だけを別のポート（別のサイト）へ転送して再現した（`docs/tools/appear/browser/appear_xorigin.js`）。
  - 直す前：同じエラーで 2D に落ちた。
  - 直したあと、転送先が CORS を許すとき：3D のまま全員に合成された。
  - 転送先が CORS を許さないとき：3D のまま本人の元の絵になり、エラーなし。2D 版も同じ。
  - 外見の確かめ一式（jsdom 28／28、ブラウザ 6 通り）も NG 0（`docs/appear/logs/tests_fix961.log`・`browser_xorigin.log`）。
- **未確認：** githack の本物のページでの確認。この作業環境からは githack に接続できない。

## 4. 外見の作り方

- **形：** ITEMS の `type` で枠と大きな形を決め、名前の言葉で細かい違いを決める（形は素材キットの 15 種）。
  - 剣：剣・大剣・曲刀・分かれ刃・木剣
  - 槍：槍・斧槍・三叉・旗槍・傘槍・時計の針
  - 重鎧：板金・鎖・鱗・胸甲
  - 軽装：革・外套・コート・布・装束
  - ローブ：ローブ・羽衣
  - 盾：凧形・円形・小盾・大盾・障壁
  - 兜：兜・竜兜・冠
  - 帽子：帽子・魔女帽・ターバン・頭巾・提督帽・額環・羽根帽子
- **同じ形の品の違い：** 配色と意匠で出す。
  - 配色はその品の絵（`assets/item-icons`）の色から取る。
  - 意匠は「潮騒」「刻針」「竜牙」などの系統の模様。
- **ボス固有装備 68 品：** ID ごとに専用の形・意匠と縁の光を決めた。
- **装飾品：** 名前の形に合わせて場所を変える（ネックレス一律にしない）。
  - 指輪 13・首 14・腰 20・胸 8・眼鏡 4・腕輪 4・耳 2・頭 1・足 1・腰帯 1。
  - 背面では、胸のブローチ・眼鏡を描かない。
- **素体：** 元の絵の写しから、持っている武器・盾を外して後ろを補う。
  - 補い方は、反対側の写し・別の向きの絵・周りの色からの補間で、ドットの大きさと元の絵の色にそろえる。
  - 帽子・頭巾は、頭の装備をかぶるときだけ外した素体を使う（リナ・セリス・ルシア・魔法使いなど）。
- **着せ方：**
  - 服・鎧は「体の形 − 顔・手・髪」の中に着せ、元の絵の明暗（ひだ・腕の輪郭）をのせる。
  - 兜・帽子は顔にかけない。
  - 武器は握っている手の下に通し、手を上に描き直す。
- **変わらないもの：** 顔・髪・体格・個人の特徴は本人の絵のまま。
- **表にない品：** あとから足した品も、`type` が知っている形なら表示する（配色は ID から）。
- **合成の回数：** 元の絵・人物ID・職業・向き・5 枠の装備ID（`signature`）が変わったときだけ合成する（最大 40 組を使い回す）。毎フレーム作らず、待機中の全員の全部の組み合わせも先に作らない。
- **合成にかかる時間：** ヘッドレス Chromium・GPU なしで測った値で、実機ではない。
  - 1 回あたり：中央値 13.9ms、最大 49ms
  - 使い回しのとき：0.01ms 未満

## 7. 未確認・未対応・代わりの表示

- **未検証：** 実機（iPhone・Android）、GPU のある環境、Windows／Mac の実ブラウザでの表示と速さ。
- **探索中の外見：** 指示どおり変えていない。
- **装備の絵：** 品ごとの手描きではなく、種類ごとの形を体に合わせて描いたもの。同じ種類の品の違いは配色・意匠で、ボス固有装備も形の土台は共有している。
- **素体の補い：** 自動。大きな盾・杖の後ろで、少しぼやけた所がある。
  - 例：オルド・カズトの正面の腰まわり、アスター・ソフィアの杖の後ろ、波刃の剣の光の残り。
  - 人物の持ち物として残したもの：セリス・エルナの本、ルシアの水、イリスの地図と背負い袋、ナギの巻物、ガネスのやっとこ、Mのドローンと端末。
- **セリスの帽子：** 頭の装備をかぶっても、向きによって大きな帽子の先が少し残る。
- **両手武器・弓と盾：** 戦闘のデータは変えていない。今のゲームで同時に装備できる組み合わせは、そのまま両方描く。
- **なかまの画面の立ち絵が変わる人：** 専用の立ち絵がなかった仲間（エルナ・ナギ・イリス・ソフィア・イオ・ガネス・アスター・オルド）。
  - 今までは村人などの代わりの絵で、これからは本人の正面の絵（合成）。
- **3Dモデルの表示：** 開発の確認用で、簡易な立体（「5」）。
- **容量：** 素体 約 7.6MB、表と部品で起動時の読み込みが約 +135KB。

# ChatGPT に絵を作ってもらうためのプロンプト（v9.10 の準備）

渡すファイルは `chatgpt_pack/`（`python3 tools/appear/pixel/chatgpt_pack.py` で作り直せる）。絵の決まりの全体は `ART_SPEC.md`。

- `style_ref.png`：絵柄の見本（今のキャラクター 4 人）
- `tmpl/<人物ID>_front.png`・`tmpl/<人物ID>_back.png`：衣装の下絵（持ち物を外した素体。1280×1280）

人物 ID：hero 主人公／kyle カイル／kazuto カズト／gald ガルド／mina ミナ／lina リーナ／seris セリス／ganes ガネス／ord オルド／lucia ルシア／elna エルナ／nagi ナギ／iris イーリス／sophia ソフィア／io イオ／aster アステル／mochipoyo 謎のタイムトラベラーM

## 進め方

1. 新しいチャットを 1 つ作り、最初に `style_ref.png` を添付して「0. 最初に送る文」を送る
2. 同じチャットの中で、下のプロンプトを 1 枚ずつ送る（1 回に 1 品。まとめて頼むと切り出せない絵になりやすい）
3. できた絵は、決まりのファイル名を付けて保存し、こちらのチャットに添付する
4. まず「試しの 8 枚」だけ作る。取り込んでゲームの中での見え方を確かめてから、残りを作る

**試しの 8 枚**：`sword_knight`・`staff_sage`・`axe_battle`・`shield_knight`・`helm_knight_front`・`helm_knight_back`・`costume_seris_festival_front`・`costume_seris_festival_back`

うまくいかないとき
- 背景が透明にならない →「背景を #FF00FF（マゼンタ）1 色のベタ塗りにしてください。品にはマゼンタを使わないでください」と足す
- 絵がなめらかなイラストになる →「もっと粗いドット絵に。輪郭は 1〜2 ドットの暗い線、グラデーションやぼかしは使わない」と足す
- 斜めになる・影が付く →「真正面から、まっすぐ縦に。影・光のにじみ・床は描かない」と足す

## 0. 最初に送る文（style_ref.png を添付）

```
これから、2D のドット絵 RPG で使う装備の絵を 1 枚ずつ作ってもらいます。
添付の画像は、このゲームのキャラクターの絵柄の見本です。これ以降の絵は、すべてこの絵柄に合わせてください。

絵柄の決まり：
- 16bit 風のドット絵。輪郭は暗い色の線、面は 3〜5 段階の明暗で塗る
- グラデーション・ぼかし・光のにじみ・アンチエイリアスは使わない
- 光は左上から
- 背景は透明（透明にできないときは #FF00FF の 1 色ベタ）
- 影・床・文字・枠・手・人物は描かない（品だけ）
- 1 枚の画像に 1 つの品だけを、画像の中央に、余白を 10% ほど残して大きく描く

準備ができたら「了解」とだけ返してください。
```

## 4. 衣装セット（正方形 1024×1024。1 人につき正面と背面で 2 枚）

`tmpl/<人物ID>_front.png` を添付して送る：

```
添付の画像は、ドット絵 RPG のキャラクターの正面の絵です。
このキャラクターの顔・髪型・髪の色・頭身・立ち位置・体の向き・手足の位置を変えずに、服だけを次の衣装に着せ替えた絵を描いてください。

衣装：【ここに衣装の説明】

決まり：
- 正方形（1024×1024）。添付と同じ大きさ・同じ位置にキャラクターを置く（足の位置を変えない）
- 両手は何も持たない。握った手の形と位置は添付のまま
- 添付と同じドット絵の絵柄（輪郭は暗い線、面は 3〜5 段階の明暗、ぼかしなし）
- 背景は透明。影・床・文字は描かない
```

背面は、`tmpl/<人物ID>_back.png` を添付して、同じチャットで：

```
添付は同じキャラクターの背面の絵です。いま描いた衣装を着た背面の絵を、同じ決まりで描いてください。衣装の色・模様・飾りは正面の絵とそろえてください。
```

衣装の説明の例（試しはセリスで）：

| ファイル名 | 人物 | 衣装の説明 |
|---|---|---|
| `costume_seris_festival_front.png`・`_back.png` | セリス（tmpl/seris_*.png） | 祭りの晴れ着。白と水色の膝丈のワンピース、胸に青いリボン、裾に金の刺繍、短いケープ。帽子はかぶらず、髪に青い花の飾り。 |

ほかの人の衣装は、どんな衣装にしたいか（例：水着・学生服・礼装・和装・悪役風）を決めてから、同じ形で説明を書く。

## 確認が必要な点

- ChatGPT が下絵の頭身・位置をどこまで守るかは、作ってみないと分からない（推測：少しずれる。ずれは取り込みのときに足もとの位置で合わせる）
- 正面と背面で衣装の細部がそろわないことがある。目立つときは作り直しを頼む
- 作った絵をゲームで公開・配布してよいかは、ChatGPT の利用規約の確認が必要（こちらでは確認していない）

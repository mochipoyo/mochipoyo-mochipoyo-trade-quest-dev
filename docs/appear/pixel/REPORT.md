## 2. 作り方

### 2-1. 装備 → 部品の種類（既存の処理を使う）

装備ID から形を決める処理は、v9.6 の `EquipmentAppearance.resolve()` をそのまま使う（ITEMS の type と、外見の表 `EQUIP_APPEARANCE_DATA` の形の違い・色）。その形を部品の種類に置き換える。

| 枠 | 形 | 部品の種類 |
|---|---|---|
| 鎧・服 | light（革・外套・布など）／heavy（板金・鱗・鎖）／robe | armor_light／armor_heavy／armor_robe |
| 頭 | helm／hat のうち witch（とんがり帽子） | head_helm／head_hat |
| 武器 | sword／staff／spear | weapon_sword／weapon_staff／weapon_spear |
| 盾 | shield | shield |

表にない形（斧・弓・短剣・こん棒・爪、とんがり以外の帽子）は部品がない。そのときは**本人の従来の絵**で表示する。

### 2-2. 部品（元の絵は書き換えない。部品は `assets/characters/equip-pixels/hero/` に別に置く）

作るのは `tools/appear/pixel/build_hero.py`。部品の座標は元の絵と同じ。

**素の絵（装備を外したとき）**
- 元の絵から剣と盾を外す
  - 剣の刃・鍔・柄頭を消す。拳の上の角は丸める
  - 盾の後ろは、体の反対側の半分を写して作る。影の側になるので少し暗くする
  - 右へなびくマントの端は写さない
- 兜用：兜からはみ出す髪を消した素の絵
- 帽子用：帽子の上へ突き抜ける髪を消した素の絵
- つばの下に出る横の髪は残す

**胴**
- 軽装・重鎧：元の絵の板金のドットを、そのままの場所で品の色に塗り直す。形は元の絵のままなので、肩当ては元の肩の上から動かない
  - 軽装は明るさの幅をしぼって、革らしく光らせない
  - 灰色の品（鉄の鎧など）の重鎧は、元の板金のまま
- ローブ（正面）：同じ画風の魔法使いの立ち絵（`jobs/mage.png`）から、布のしわ・金の縁取り・裾の模様を借りる
  - 主人公の体格に合わせて、下へ行くほど横に広げ、左右に写した
  - 袖・肩は、主人公の腕と肩当ての形のまま布の色にした
  - 裾の下の脛当ては茶色の靴にした
- ローブ（背面）：マントの下に見える裾を描き、腕の板金を布の色にした。マントはローブより手前に出す

**頭・武器**
- 兜・とんがり帽子・杖・槍の穂先は描いて作った
  - 色は主人公の鎧の色と金具の色に合わせ、光は左上から当てた
  - 主人公の胸当ての板金のムラを写して、元の絵と同じ描き込みの手ざわりにした
- 剣と盾は、元の絵から切り離したもの（正面・背面それぞれ）

**色**
- 色を変える部分は灰色の層にしておき、品の色（装備の絵から取った色）の 5 段で塗る
- 灰色の品（鉄・鋼）は、主人公の鎧の板金の色を使う
- 杖の玉は、品の差し色で塗る（樫の杖は緑、魔導の杖は青）

### 2-3. 重ね順・握り位置

| 向き | 握る位置（武器） | 盾の位置 | 重ね順 |
|---|---|---|---|
| メニュー正面 job:warrior | 22, 117（左の拳） | 105, 125（右腕） | 素の絵 → 胴 → 頭 → 盾（腕の上）→ 武器 →（杖・槍のときは）拳を柄の上に描き直す |
| 戦闘背面 back | 205, 213（右の拳） | 108, 222（左腕の外側） | 同じ |

- 剣：鍔が拳の上に重なる（剣を後に描く。元の絵と同じ）
- 杖・槍：柄が拳の中を通る（柄の上に拳を描き直す）

### 2-4. 足もと・大きさ・立ち位置

- 合成の絵は「元の絵＋まわり 48 ドットの余白」。どの組み合わせでも同じ大きさで、足もとの基準点は元の絵のまま
- 槍の穂先・杖・帽子の先は余白の中に出る
- メニュー：元の絵と同じ範囲・同じ左右の中心で切り出す。人物の大きさと位置は元の立ち絵と同じ。はみ出す先だけ枠の外へ出る
- 3D の戦闘：基準点を余白の分だけずらして切り出す（v9.6 と同じ）。カメラ合わせ・影・HP の位置は、元の絵の範囲を使う

### 2-5. 部品のないとき

- 部品がない人物・向き・装備の形のときは、**本人の従来の絵**（剣・盾を持った元の絵）で表示する。理由は `EquipmentAppearance.unsupported()` とコンソールに記録する
- 装飾品は描かない（試作の対象外）。記録だけで、ほかの装備は着替える
- v9.6 の描き足し（vector）は、開発の見比べ用に残した（`EquipmentAppearance.setMode('vector')`）。ふだんは使わない

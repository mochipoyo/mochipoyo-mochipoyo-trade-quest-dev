# 次の対象：リーナとガルド（装備の外見・ドット絵の差分）

主人公（v9.7・v9.7.1）の仕上がりを確かめたあと、次はリーナとガルドに広げる。この文書は、そのための下調べと手順の案。
**まだ作っていない**。いまのゲームでは、2 人とも本人の従来の絵で表示する。

元の絵を並べた図：`shots/next_lina_gald_sources.jpg`（同じ 2 倍。赤い線＝足もと）

## 1. 体格の違い（元の絵を測った値）

| | 主人公 | リーナ | ガルド |
|---|---|---|---|
| 立ち絵の大きさ | 130×200（`jobs/warrior.png`） | 195×274（`companions/lina.png`） | 255×277（`companions/gald.png`） |
| 立ち絵の人物の高さ | 196 | 270 | 273 |
| 立ち絵の幅（上から 45% の行） | 107 | 153 | 216 |
| 背面の人物の高さ（320×320・足もと 160, 304） | 201 | 270 | 266 |
| 背面の幅（上から 45% の行） | 123 | 153 | 194 |
| PartyDirections の referencePixelHeight・worldHeightRatio | 206・1 | 278・1 | 278・1.08 |

- メニューの立ち絵は、枠の高さ（PC 300px）に合わせて縮める。そのため、1 ドットの大きさが人によって違う
  - 主人公：約 1.3〜1.5 倍
  - リーナ・ガルド：約 1.1 倍
- 主人公の部品（兜・帽子・杖・槍など）を拡大・縮小して使い回すと、ドットの粗さが合わない。同じ作り方で、人ごとの大きさで作り直す必要がある（推測：拡大・縮小すると、ぼやけるか粗くなる）

## 2. 人ごとの難しい所（元の絵を見た所見）

**リーナ**（僧侶。白い法衣・白い頭巾・長い桃色の髪・大きな飾りの杖）
- 背面の背中は、ほとんど長い髪で隠れている
  - 鎧・ローブの差分は、髪の下に入れる必要がある。主人公のマントと同じく「髪を手前に描き直す層」が要る
  - 兜は、長い髪のどこまでを兜の下に入れるか決める必要がある
- 元の絵がすでに法衣（ローブに近い）姿
  - 「装備なし」の素の絵を何にするか（法衣のまま／旅装に替える）は確認が必要
- 杖が体の前にある。剣の代わりに切り離し、握る手を描き直す必要がある（正面・背面とも）

**ガルド**（戦士。大きな体・毛皮の肩掛け・腕は素肌・赤い腰布・大きな斧）
- 胸と肩が広い。重鎧・軽装の板金は、元の絵に板金がないので描いて作る（主人公のように、元の板金の色を塗り直す方法は使えない）
- 毛皮の肩掛けを、鎧の上に出すか下に入れるか決める必要がある
- 大きな斧が体の右に重なる。切り離し、斧の後ろの体と腕を補う必要がある
  - 主人公の盾と同じく、反対側を写すか描き足す
- 兜は、逆立った髪とひげの扱いを決める必要がある（正面）

## 3. 手順の案（主人公と同じ流れ）

1. 人ごとの作り方 `tools/appear/pixel/build_<人物ID>.py` を書く（主人公の `build_hero.py` の道具 `pxlib.py` を使う）
   - 武器・盾の場所と、外したあとの補い方
   - 体の中心、髪・頭の範囲（兜・帽子で消す髪）
   - 鎧の範囲（素の絵・重鎧・軽装の差分）
   - 握る位置・盾の位置・重ね順
2. `EQUIP_PIXELS.actors.<人物ID>.views` に、メニューの立ち絵（menuBase）と戦闘の背面を書き出す
3. 確かめ：`appear_pixel_test.js`・`browser/appear_pixel.js`・`browser/appear_pixel_ui.js` に人物を足す
   - ふつうの手順（装備メニュー → そのまま戦闘）
   - PC とスマホ縦の両方
4. 見比べ：主人公と同じ 6 つの組み合わせと、ローブだけ・重鎧だけ

## 4. 先に決めたいこと（確認が必要）

- リーナの「装備なし」の素の絵：いまの法衣のままにするか、旅装に替えるか
- ガルドの毛皮の肩掛け：鎧より手前に出すか、下に入れるか
- 職業を変えたときの扱い：仲間の絵が職業で変わるか（主人公は v9.7.1 で、どの職業でも本人の素体で着替える）
  - 仲間の立ち絵が職業で変わるかどうかは、まだ確かめていない（未確認）

## もっちーの操作

1. ZIPをClaude Codeが開いているプロジェクト内の `reference/environment-overhaul-v1/` などに展開。
2. 下記の文を送る。
3. Claudeが返したプレビューで、まずポヨ村・リヴェル城・鉄鎖鉱山・ノード・トレディアの違いを確認。

```text
添付したTradeQuest_Environment_Overhaulの01_CLAUDE_START_HERE.mdを読み、現在のfeature/3d-fullへ環境リデザインを実装してください。資料を読むだけ・計画を出すだけで終わらず、コード・マップ・素材の接続・ビルド・検証まで行ってください。既存の物語、仲間の3Dモデル、戦闘、セーブ互換を維持し、町の間取りと建物形状、ダンジョンの空間構成を変えてください。色変更と小物追加だけでは完了にしないでください。最初の5地点で基準を作り、全330マップへ展開してください。未完成は明記し、完成数に含めないでください。
```

## 確認用ビューア（Claude側）

```bash
cd reference/environment-overhaul-v1
npm install --ignore-scripts
npm test
npm run preview
```

`http://localhost:8790/preview/` を開く。部品を選択すると回転・拡大できる。テクスチャは2×2反復表示で継ぎ目を確認できる。

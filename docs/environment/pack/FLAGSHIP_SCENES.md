# 最初に完成させる5地点

位置は2026-11-04に抽出したsnapshotを基準とするが、実装前に再取得する。以下の設計は新規提案で、現在のゲームの事実ではない。

## 1. ポヨ村 / poyo_village / 48×40

目標：画面を見ただけで始まりの農村と分かること。

- 中央付近の大樹と低い石囲いを中心に、曲線の生活道と小さな広場を組む。道幅は一定にしない。
- 東の農地は畝・用水・作物・低い土手でまとめる。新しい川を横断不可の壁として追加しない。
- 村長宅は太い梁と低い大屋根、道具屋は外の棚、宿は暖炉と広い軒、教会は小さな鐘、修行場は静かな庭と違う棟の向き。
- 水車は用水の実在位置と整合させて設置。水がない場所に飾りとして置かない。
- 大樹は細い円柱と球1個にしない。幹の分岐、根、密度が異なる樹冠、影の層を作る。
- 使用候補：half_timber_bay、roof_gable、market_stall、waterwheel、stone_courtyard、wood_oak。
- 追加制作：村固有の大樹、茅葺き屋根の高品質形状、作物・花壇、家ごとの入口周り。
- 6建物と仲間/NPCの加入・会話、南の出口、探索ポイントを保持。後段の拡大により入口は複数セルあるため単一セルだけ直さない。

## 2. リヴェル城 / rivel_castle / 30×28

目標：城下町から入った瞬間に材質と天井の高さが変わること。

- 入口から奥へ儀礼の軸を通し、中央の水盤または床紋様、その脇の列柱、奥の大アーチを配置。
- 主軸は広く、側廊は狭く。左右完全コピーは避け、一方は庭/採光、他方は執務/警備の気配。
- 1階は公共性、2階は政務、3階は王家、地下は保管/警備として家具と光を変える。
- 使用候補：arch_round、column_classic、floor_medallion、courtyard_fountain、parapet。
- 追加制作：城固有の紋章、窓、手すり、城外観の塔と稜線。
- 既存の王、兵、階段、鍵、イベントを維持。列柱が会話対象への最後の隣接マスを塞がない。

## 3. 鉄鎖鉱山 / iron_mine_1 / 30×16

目標：迷路ではなく「鉱石を掘り運ぶ場所」と分かること。

- 入口は低く、途中の採掘室は広く、縦坑が見える見せ場へ展開。
- 運搬路に沿うレール、脇に古い採掘枝、岩肌の鉱脈、場所に応じた支柱。レールが壁に不自然に消えない。
- 掘られていない面は自然の岩、作業場は人が削った面として区別。
- 2階は労働/拘束の痕跡、最深部は巻上設備と看守長の場。廃坑道は梁の破損と静けさ。
- 使用候補：mine_support、minecart、rail_section、ore_lift、rock_cluster、stalagmites。
- 追加制作：まとまった岩壁パネル、鉱脈、鎖、吊り照明。
- 宝箱/ボス/階段/帰還の動線を検証。縦坑の見た目だけで歩ける床を消さない。

## 4. 演算都市ノード / node_city / 40×30

目標：中世の家を青くした町にしない。

- 六角系の公共区画、直線の配管帯、規格住居、中央データ塔で輪郭を構成。
- 登録所は高い入口、学校は閉じた中庭、配給は庇と待機列、住居は低い規格棟、市場は人の手で不規則に増えた物。
- 主材は白い外皮と青灰の金属。発光は細い線と機器の一部だけ。
- 既存 `zeromea_reformed` による外観変化を維持し、改革後は暖色灯、植木、生活の掲示を増やす。
- 使用候補：server_pillar、pipe_bridge、metal_industrial。
- 追加制作：ノード固有の建物外殻3型、制御門、冷却塔、窓/ダクト/サービスハッチ。
- 8建物の入口、学校の屋上、配給などのイベントを維持。近未来化を新しいゲームシステム追加と混同しない。

## 5. 相場都市トレディア / tradia / 48×40

目標：経済活動の中心が空間から伝わること。

- 証券市場の前を放射状の広場にし、価格の鐘と板表示を中心に置く。
- 銀行は重い石と狭い窓、取引所は広い列柱、闘技場は大きなアーチ、研究所は観測器、酒場は小さな入口と暖色。
- 深緑の銅屋根と象牙色の石を主に、真鍮を少量。チャート画面を全ての壁に貼らない。
- 大通り、裏の飲食路、住宅路で密度と床の摩耗を変える。
- 使用候補：column_classic、arch_round、floor_medallion、clock_monument、market_stall。
- 追加制作：取引所の固有正面、板表示の3Dフレーム、価格の鐘、銀行の扉、闘技場入口。
- 15建物と既存のトレード学習/闘技場/取引所の処理を保持。派手な相場表示が決定ボタンを奪わない。

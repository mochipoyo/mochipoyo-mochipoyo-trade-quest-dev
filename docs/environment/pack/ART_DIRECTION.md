# アート方針と合格の目安

## 画風

手作りのミニチュアの温かさと、石・木・金属の説得力を両立させる。キャラクターの読みやすさを優先し、風景だけを写真のようにして浮かせない。現行3D人物の体格を基準に扉・階段・手すり・家具の寸法を合わせる。

参照画像から採り入れる要素は、手前・中景・遠景の層、石の目地と欠け、木の木目、厚みのある壁、丸いアーチ、生活用品、暖色と寒色の対比、曲がり角の先の見せ場。極端なDOFやBloomで形状不足を隠さない。

## 空間と形

- 町は「入口→目的を示す目印→暮らしの地区→別の出口/戻り道」を設計。広場と路地の幅を変える。
- 建物は基壇・壁・梁・屋根・軒・窓・扉を分け、文化と用途で比率を変える。すべて同じ長方形の家にしない。
- ダンジョンは人工の直線と自然の曲線を区別。自然洞窟の岩肌は通行空間を囲む形状を作り、四角い壁に岩textureを貼るだけで終わらせない。
- 高低差は観察・移動・影に一貫して反映。単なる装飾の高台は主人公が乗れないことを明確にし、歩ける段差はheightAtとcollisionへ反映。
- 後方の遠景は低LODで作り、入口周辺やカメラに近い縁は丁寧に作る。

## 素材

同じ町でも、主道の磨耗、壁の基部の湿気、屋根の風化、仕事場の汚れを局所的に分ける。全体へ均一のノイズをかけない。

同梱6画像はAIで生成したベースカラー候補で、厳密なシームレス保証や計測済みPBRデータではない。`preview/`の2×2表示で継ぎ目を確認し、目立つ場合は大面積の無制限反復を避け、既存の良好なタイル素材・3Dの目地・異なる床割りと組み合わせる。画像を無理に法線化して影の方向を二重化しない。

粗さ/金属度の初期値はdata/materials.jsonにある。金属度を高くしてよいのは金属の領域。石・木は原則0。汚れや錆のmetalness分離は追加制作で行う。

既存素材を使うべき領域：土・草・茅葺き・瓦・布・水。高品質の追加素材を導入するなら出所・ライセンス・ファイル・採用箇所を記録する。未取得の素材が存在する前提で実装しない。

## 光とカメラ

- 主光源1つ＋空の拡散光＋限られた局所灯。ランタン全てに影付きPointLightを置かない。
- 主人公の足元と道を最も読みやすくする。危険な地形や通れない段差は輪郭で区別する。
- 夜や暗黒の背景は暗くしても通路の明度を潰さない。
- PCは必要なら軽いAO。スマホは接触影の代替や頂点色を検討し、ポスト処理より形状を残す。
- 既存のCutoutを新材質にも接続。玉座・高い柱・大樹で主人公が完全に消えない。
- カメラ値を全マップで固定しすぎないが、操作感は一定にする。会話時のカメラとUIも確認する。

## 各地の違いを確認する方法

名前とUIを隠したスクリーンショットを並べ、町5件・ダンジョン5件が色以外でも識別できるか確認する。区別に必要な要素は、輪郭、空間の比率、街路/床割り、固有の目印、生活道具。壁や屋根の色だけで区別できる状態は未完成。

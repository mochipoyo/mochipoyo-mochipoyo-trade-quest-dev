# v7.8 未来の地球（ワールドマップの作り直し）と新しい 5 地域

依頼（2026-11-06 07:11）：シームレス移動の 3D 版を基に、ワールドマップを「実際の地球に近い未来の地球」に作り変え、
歩けるフィールド・航行できる海・世界地図・ミニマップに同じ地形を使う。既存の町・城・港・ダンジョンは残して地域ごと再配置し、
新しい 5 地域（錆雨市ネオン・ドック／浮天城アエリア／環星ステーション・オルビス／環潮大陸ネレイア／灰岸都市メリディアン）を足す。

- ブランチ：開発リポジトリ `feature/earth78`（`feature/env-overhaul` の 5994ca6 から）。本番（mochipoyo-trade-quest の main）には出していない。
- 対象：**3D 版（`3d/index.html`）だけ**が地球の世界になる。2D 版（`index.html`）は前のまま（地球の地形のデータを読まない）。
- 新しい 5 地域も地球の世界だけ。2D 版・3D 版の設定「v7.6 の配置」「地域ごと」では、新しい地域の地図・敵・案内・外観・ボスの姿を読み込みの最後に外す（`R78.finish`）。
  アイテムとクエストの定義は残す（地球の世界のセーブを読んでも持ち物・クエストの画面が壊れない。クエストは `future`＝掲示板に出さない）。
- 3D 版の 3D設定「世界のつながり」で、前の方式（「つなぐ（v7.6 の配置）」＝10 地域の配置、「地域ごと」）に戻せる（localStorage `mtq3d-join`＝`on`／`v76`／`off`。ページの再読み込みで反映）。

### 座標の変換
- 前の地域の地図の座標 ⇔ 地球の座標：地域ごとに、主な場所の対応（pins）から最小二乗で拡大・平行移動を決め、ガウスの局所補正（σ=9）で合わせる。
  `MapRemake.maps[id]`（版 `e78.2`）の `mapPos`／`mapBack` として登録 → `World.enterMap` が前の座標を自動で変換（`{raw:true}` で変換なし）。
- 前の地図の物（町・宝箱・人・出来事）は、変換のあと、歩ける所・同じつながりの区域へ寄せる（`Earth78.EXACT`）。
- 前の地域の中の歩けるつながり（入口・宝箱・人・出来事どうし）が 2D 版と同じことを自動で確認（`earth78_check.js`）。

## 4. セーブの引き継ぎ（`js/rpg/earth78.js`）
- 読み込み時に `World.start` の前で変換。地域ごとに `remakeVer[地域] = 'e78.2'` を付ける（二重に変換しない）。
- 前の版（`e78.1`）の地球のセーブ：配置を変えた地域（アルカディア・カリオン・マクディア。`L.prev`）は、その版の配置 → 旧座標 → いまの配置へ直す。変えていない地域は印だけ新しい版へ（`Earth78.upgradePrev`）。
- 変換するもの：主人公の位置・乗り物（帆船・遠洋航海船・飛空艇）・アストラ号（置き場所と飛び立った場所）・ダンジョンの入口・訪れた所。
  変換した先が海・壁のときは、近い安全な歩けるマス（乗り物は近い海）へ。
- 2D 版・前の方式（地球の世界を使わない設定）で読むと、前の座標へ戻す（`migrateOff`）。自動で作る地図（`w78_*`）にいたときは近い前の地域の歩けるマスへ
  （その版の地形で寄せる。旧座標で決めた位置は二重に戻さない＝`e78skip`）、新しい地域にいたときは最後に泊まった宿へ（2D 版には新しい地域がない）。
- 元のセーブの枠は書き換えない形のまま（追加の項目だけ）。v7.6 の共通の海（`sea76_*`）にいたセーブも地球の世界へ移す。
- LocalStorage のキーは前と同じ（2D 版と共有）。地球の世界で保存したセーブは、2D 版で読むと上のとおり前の座標に戻る。

## 5. 世界地図・ミニマップ・案内
- ミニマップの「世界」と全体図：地球の地形から 1 マス 1 画素の画像を作って描く（`js/ui/minimap.js`）。地域の名前を地球の上に表示。
- 世界の絵の地図（`js/ui/worldmap.js`）：地球の画像を背景に、地域・新しい地域・アエリア・オルビスの印。
- 案内（`js/rpg/nav.js`）：となりどうしの地図の道で計画。案内の文のうち、前の配置を前提にした言い回し 18 か所を地球の配置に合わせて置き換え（3D 版の地球の世界だけ）。
- アストラ号：地球の座標で飛ぶ（東西一周）。観測記録は元の 12 か所。

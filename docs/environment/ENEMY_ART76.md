# 敵7体の新しい形・町の人の装い：素材の仕様（v7.6・2026-11-05）

この作業環境では画像を生成できないため、**コードで描いた仮の絵**（ドット絵・小さな立体の組み合わせ）を入れています。
本番の画像素材ではありません。下の仕様で素材を作れば、同じ仕組み（敵は `EnemyArt` の画像の表、町の人は歩く絵の表）に差し替えられます。

## 1. 敵7体（新しい絵の検品で「保留」だった敵）

いままでは共通の種族の形（アンデッド・爬虫類・獣・ゴーレム・悪魔・虫・相場の魔物）を色だけ変えて描いていました。
v7.6 から `js/core/monsterart76.js` の形で描きます（データの `ENEMIES[id].art` は変えず、描くときだけ読み替え。`?enemyart=old` で従来の形）。

| 敵ID | 名前 | 仮の形（いま） | 本番の素材の仕様（案） |
|---|---|---|---|
| skeleton | スケルトン | 骨の剣士：欠けた兜・赤く光る目・肋骨・丸い盾・錆びた剣・破れたマント | 512px 透過PNG。正面やや左向き、全身。盾は左手・剣は右手。色：骨 #e8e4d8・マント #7a2430 |
| lizard | ダマシトカゲ | カメレオン：巻いた尾・色の変わる縞（4色）・兜のような冠・回る目・長い舌・枝をつかむ足 | 横向き、枝の上。縞は黄・青・桃・薄緑（「だます」体の色）。目は大きく別々の向き |
| mole | 反転モグラ | 土の山から出るモグラ：大きな爪・桃色の鼻とひげ・ヘルメットの灯り・頭の上の「反転」の円い矢印 | 正面。両手の爪を広げる。矢印は青緑 #5ae0c8（相場の反転の印） |
| golem | ストーンゴーレム | 積み石の巨人：苔・胸の光る紋（水色）・目の切れ込み・石を重ねた腕と大きな拳 | 正面、どっしり。紋は #5ad8ff で光る。苔 #5a8a3a |

- 画像を入れるとき：`js/data/enemy-redesign.js` の表の `status: 'held'` を `adopted` に、`file`・`bbox` を足す（名前も新しくする場合は一組で変える決まり）。
  画像が採用されると `EnemyArt` の画像が優先され、この仮の形は使われなくなります。

## 2. 町の人の装い（同じ絵の村人・子ども・老人・商人）

`js/data/mob76.js`（どの人に何を付けるか・2D のドット）と `three-src/src/entities/MobDress76.js`（3D の小さな立体）。
NPC の ID で決まった1つ（または「なし」）を選ぶので、毎回同じ人が同じ物をかぶります。データ・会話・セーブは変えていません。

| 地域 | かぶり物（仮） |
|---|---|
| アルカディア | 麦わら帽子・頭巾（色は人ごと） |
| グラニア（鉱山） | 灯りつきのヘルメット・頭巾 |
| カリオン（王都・徴収都市） | ベレー帽・頭巾 |
| 島々・港 | バンダナ・麦わら帽子 |
| 砂漠 | ターバン（宝石）・ベール |
| 鐘の都・学院 | シルクハット・ベレー帽 |
| 機械の島（ゼロメア） | 光るバイザーの帽子 |
| 魔導王国 | とんがり帽子（星）・ベレー帽 |
| 雪国 | 毛皮の帽子・ニット帽（ぽんぽん） |
| 火山（鍛冶街） | ゴーグル・頭巾 |
| 天空 | 羽根の飾り |
| 虚無の荒野 | 頭巾（フード）・ヘルメット |

- 本番の素材にするなら：2D は歩く絵（16×24・4方向×3コマ）を地域ごとに描き分けたシート、3D はモデルの帽子の部品（頭の骨 `head` に付ける GLB）。
- 3D設定「建物の作り込み」を「使わない」にすると 3D のかぶり物は付けません（2D は付けます）。

# 西暦3121年の物語：実装状況（v6.9）

- ブランチ：`feature/story-3121-world`（基準：`feature/3d-full` の 62900a3）。公開版（mochipoyo/mochipoyo-trade-quest の main）は変更していない
- データ：`js/data/story3121.js`（プロローグ・アサナ村4状態・回想・母の手紙・誘惑・帰郷）、`js/data/story3121-world.js`（財団・波形教・各章の出来事・任意クエスト・記録帳・案内）
- 既存ファイルの変更は最小限：`js/ui/title.js`（新規ゲームの分岐）、`js/data/towns.js`（村長の最初の一言・リーナの問いかけ）、`js/rpg/world.js`（NPC の showWhen・マップ固有の色）、`js/ui/menu.js`（読める重要アイテム）、`js/data/finale.js`（帰郷・おかえり）、`js/data/sky.js`（焚き火）、`js/data/world-kalion.js`（アサナ村跡の場所）、3D（`MapScene3D` 炎・煙・魔物の姿の NPC、`CameraController3D`・`GameBridge` イベント用カメラ、`LightingManager` マップ固有の空気）

## 凡例

| 記号 | 意味 |
|---|---|
| 実装 | コードに入っている |
| 2D検証 | jsdom の自動テストで、ゲームの処理（会話・フラグ・アイテム・マップ移動）として発生を確認した（`work/s3121/prologue2d.js`・`chapters2d.js`）|
| 3D検証 | Playwright＋Chromium（ソフトウェア WebGL）で 3D のページを動かして確認した（`three-src/tools/test3d/p69a_prologue3d.js`）|
| 未検証 | 自動テストでは確かめていない（手で遊んでの確認・実機・GPU も含む） |

**実機（スマホ・GPU のある PC）での確認は、すべて未実施です。** 3D は作業環境のソフトウェア描画での確認だけです。

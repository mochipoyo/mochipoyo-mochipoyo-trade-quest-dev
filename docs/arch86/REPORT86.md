# v8.6 飛空艇を呼ぶ（F キー）

依頼（2026-11-08）：飛空艇を入手後に、特定のキーで呼び出せるようにする。

## 1. 変更前（確かめた事実）
- 飛空艇（`js/rpg/vehicle.js`・`js/data/vehicles.js`）は、第十四章の起源の実験室の格納庫で `airship_owned` を立てると、母港（マクディアの地域）に現れる。
- 乗るには、飛空艇の止まっているマスへ歩いて行く必要があった。
- 離れた所から戻す手段は、メニュー「ファストトラベル」→「乗り物を母港へ戻す」だけ（今いる所へは呼べない）。

## 2. 変更後
- **F キー**で、飛空艇が今いるマスへ来て、そのまま乗る（飛び立つ）。2D 版・3D 版の両方。
- **スマホ**：操作パネルに「**飛空艇**」ボタン（持っているときだけ出る。乗っている間は光る）。
- **メニュー**：「**飛空艇を呼ぶ**」（持っていて、乗っていないとき。「ファストトラベル」のすぐ下）。
- **呼べる場所**：外のフィールド（地図の種類 field：地上の地域の地図）だけ。
- **呼べないとき**（短い通知を出す。飛空艇の位置は変わらない）：

  | 状況 | 通知 |
  |---|---|
  | 持っていない | 呼べる乗り物がない（物語の先が分からないように、飛空艇の名前は出さない） |
  | 町・ダンジョン・建物の中 | 飛空艇は外のフィールドでだけ呼べる（町・ダンジョン・建物の中では呼べない） |
  | 船に乗っている | 小型帆船（など）を降りて、陸に上がってから呼ぶ |
  | もう飛空艇に乗っている | もう飛空艇に乗っている（決定キーで着陸。草原・砂地・道などの平地のみ） |

- **キーの細かい決まり**
  - **Ctrl・Alt・⌘ と一緒の F**：反応しない（ページ内検索の Ctrl＋F などはそのまま）。Shift＋F（大文字）は反応する。
  - **会話・戦闘・メニューの間に押した F**：捨てる（あとで勝手に呼ばない）。
  - **2D 版で 1 歩の途中に押したとき**：その 1 歩が終わってから呼ぶ。
- **3D 版の見せ方**：呼ぶと、飛空艇が空（高さ 24）から 1.4 秒かけて降りてくる。降りる間は主人公が見えていて、着く直前に乗る（主人公が隠れる）。見た目だけで、乗る処理は呼んだ瞬間に終わっている。2D 版は通知と音だけ。
- **馬車**：馬車に乗っていても呼べる。飛空艇の間は馬車を使わず、着陸すると馬車に戻る（馬車の設定は覚えたまま）。
- **変えていないこと**
  - 着陸（決定キー・平地のみ）、母港へ戻す（ファストトラベル）、全滅で港へ戻る。港は「最後に乗った所」なので、呼んで乗った所になる。
  - 飛ぶ速さ（歩きと同じ。データの speedMul はもとから使われていない）。
  - 飛空艇の解放の条件。
- **セーブ**：形は変えない。呼ぶと `State.data.vehicles.airship` の map・x・y・port が今いるマスになり、`aboard` が `airship` になる（ふつうに乗ったときと同じ）。古いセーブもそのまま読める。
- **案内**：「次の目的地」で飛空艇が必要なのに近くにないときの案内を、「フィールドで F キー（スマホは「飛空艇」ボタン）を押すと、今いる所へ呼べる。」に変えた（前は「母港へ戻す」の案内）。
- **操作説明**：PC の右の欄「操作方法」に「F 飛空艇を呼ぶ（手に入れたあと・フィールド）」、スマホの操作説明に「飛空艇」ボタンの説明、README の操作の行に F を足した。

## 5. 未確認・注意
- 実機（PC・スマホ）での操作と見え方。この環境の 3D 版のフィールドは 1 秒に 1〜2 コマなので、降りてくる様子は数コマしか記録できていない。
- スマホの横画面（左右の余白が狭いとき）は、馬車と飛空艇の両方を持つと補助ボタンが 2 段になり、ゲーム画面の下の方が前より隠れる（押すことはできる・重なりなし）。
- 物語の場面で飛空艇に乗っていてはいけない所が、フィールドの中にあるかは確かめていない。飛んでいる間は町・洞窟・イベント・敵に入らない作り（もとから）なので、物語の進み方は飛び越えない、と考えている（推測）。

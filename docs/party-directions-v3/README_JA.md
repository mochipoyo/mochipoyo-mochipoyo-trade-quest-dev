# トレードクエスト 味方4方向素材 v3

主人公＋仲間14人、計15人を実際のゲーム定義とPNGに照合して制作した素材です。

## Claudeへの渡し方

このフォルダをZIPのままClaudeへ添付し、`docs/CLAUDE_INTEGRATION_PROMPT.md` の全文を指示として渡してください。ゲーム本体への適用はまだ行っていません。

## 画像の内訳

| 区分 | 人数 | 正面 | 背面・左・右 |
|---|---:|---|---|
| 主人公・リーナ・カイル・ミナ・セリス・ガルド・ルシア | 7 | 既存PNGの画素を保持 | 21枚を新規制作 |
| エルナ・ナギ・イーリス・ソフィア・イオ・ガネス・アステル・オルド | 8 | 新規8枚 | 新規24枚 |

実装用60枚は `sprites/`。全て320×320の透過PNG。`previews/index.html` を開くと人物ごとの4方向と背景色切替を確認できます。

新規8人の外見は、ゲーム中の職業・経歴・人物像を基に今回デザインしたものです。既存の正面画像では見えない背面の衣服・装飾は、正面と整合するよう補完しています。

## 本人の外見を維持する仕様

人物IDから画像を選びます。転職先の汎用画像で本人を置き換えません。このパックは基本衣装のみで、20職業分の着替えや動作の連番画像は含みません。追加衣装がない職業では同じ本人の基本衣装を表示する設計です。

## 内容

- `sprites/`：実装用60PNG。
- `source_sheets/`：15人の生成原寸シート。各画像は1254×1254。
- `original_front/`：既存正面7PNGの原本。
- `manifest.json`：方向別パス・サイズ・基準点・切り出し範囲・ハッシュ。
- `docs/character_roster.csv`：人物ID、名称、初期職業、元画像、制作区分。
- `docs/character_data.json`：取得した仲間14人と職業20種の定義。
- `docs/CLAUDE_INTEGRATION_PROMPT.md`：ソースを確認して書いた実装指示。
- `docs/QA_REPORT.json`：画像の機械検査結果と検証範囲。
- `prompts/`：各人物の制作プロンプト。画像生成機能で制作し、切り分け・余白調整・縮小のみ機械処理。
- `integration/`：人物IDを優先する参照コード。実装済みパッチではありません。

PNGの透過・サイズ・ID・欠落・画像端の余白を検査し、方向別一覧を目視確認しています。既存正面7人の描画画素に変更がないことも比較済みです。ゲーム組み込み、実際のカメラ表示、スマホでの速度と画質は未検証です。

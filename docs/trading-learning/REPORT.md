## 4. 手法の「確定している基準」と「推奨仮設定」

| 区分 | 項目（初期値） |
|---|---|
| **確定している基準**（共有された設定） | 上位足：日足・4時間足／エントリー足：5分足・15分足／EMA 20・30・40（20＞30＞40 で上昇の並び）／RCI 期間 9・±70 付近からの反転に注目／MACD 6・13・4 の通常・ヒドゥン／確定した高値・安値とダウ／複数の根拠の合致を重視（EMA の並びだけ・RCI の±70 到達だけで入らない）／損切り必須／RR 1:1.5〜1:3 を目安に検討／ロット過大・飛び乗り・根拠不足・レンジでの無理なエントリーを避ける |
| **推奨仮設定・変更可能**（※。もちぽよ公式の機械売買ルールではない） | RCI の反転：±70 に触れたかを見る本数 8・最小の戻り 10・確認 1 本・有効 8 本・再逆行 10／ダイバの有効 24 本・MACD の山谷を探す範囲 ±2 本／RCI の反転を必須（する）／ダイバを必須（しない）／必要な根拠の数 2／上位足と逆（入らない）・日足と4H の食い違い（入らない）／損切りの余裕 3pips／許容損失の上限 2%／飛び乗りの距離 EMA20 から ATR×2.2／利確を必ず決める／上位足の向き＝EMA の並び、なければダウ |
| 一般FX学習（general） | ブレイク・レンジの端・押し目も根拠に数える。RCI の反転は必須にしない。上位足と逆は注意だけ（いろいろな手法を否定しない練習用） |

画面では、設定の一覧に「推奨仮設定」「共有された基準」の区別と、変えた値の印を出す（メニュー → もちぽよ実践トレード道場 → 設定）。

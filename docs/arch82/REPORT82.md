## 3. 対象ごとの結果

### 3.1 全町の屋内（間取りと作り方）
- **間取り（2D・3D 共通の論理）**：`js/rpg/layout82.js`。町の建物の入口から中のワープでつながる部屋（上の階・奥の部屋を含む）を、ID の前方一致に頼らずに所属の町へ割り当てた：**456 室**（地球の世界。2D 版は同じ規則）。
  - 用途を判定（宿・酒場・道具屋・武器屋・防具屋・銀行・教会・ギルド・道場・長老の家・民家・塔・図書・研究・郵便局・時計塔・倉庫・館、上の階は `_up`）し、用途の「区画」（宿＝受付と客室、酒場＝カウンターとブース席と暖炉、民家＝居間と寝室と台所、銀行＝窓口の格子と金庫…）を間仕切りの壁と家具で置き直した：**388 室**（2D 版の世界は 372 室）。
  - 町ごとの違い（FLAVOR）：暖炉の有無・ブース席・低い座卓・共同の寝床・二重の玄関・同じ形の区画のくり返し（ノード・定時街区）など。
  - 変えない物：部屋の大きさ・外の壁・扉・ワープ・階段・人の立つマス・出来事・宝箱・調べる所・クイズの魔物・ほかの地図から着くマス。置くたびに「出口から全部の人と話せる（カウンター越しでもよい）・出来事・宝箱・ワープへ行ける」を確かめ、だめなら置かない。
  - 変えなかった 68 室：台本が座標を使う・作り込み済みの専用の部屋 16、ポヨ村の作り込んだ部屋 15、城（城の作り方で別に扱う）14、ほかの作り直しの地図 13、v8.2 で専用に作った部屋（学院の本校舎）6、屋内でない 4。
- **3D の作り方**：`three-src/src/environment/theme82.js`（町ごとの表）・`recipes/interior82.js`（壁・腰板・窓・天井・灯り・敷物・間仕切り）・`recipes/furn82.js`（家具 30 系統）・`recipes/tex82.js`（壁紙・煉瓦・寄木などの手続きの画像）。
  - 作り方は **38 種**（町 30・物語の状態 5〈アサナの襲撃の夜・壊滅後・復興、ネレイアの満潮・干潮〉・城郭区画 3）。決め方：地図の明示 → 部屋の用途 → 所属の町 → 地域。
  - **色以外の差**（壁の作り・腰板・床の張り方・窓・天井・灯り・家具の系統・暖炉・間仕切り・敷物・町の品）：ちがう町どうしの全 703 組で最小 4（`docs/tools/v82/theme82_diff.mjs`・`logs/theme82_diff.log`）。前（v8.1）の共通の部屋との差は全部の町で 6 以上。同じ町の家族（城郭区画と城下町・状態の地図）は別に数えた（差 0〜10。数えない組として記録）。
  - 低画質（スマホの既定）では点の光が 4 つまでなので、屋内のまわりの光を上げた（最初の版では暗い木の床の町がほぼ黒く見えたため直した）。

### 3.2 マクディア（古いロンドン風）
- 屋内（宿・酒場・民家・道具屋・武器屋・教会・塔ほか、マクディアに属する全部の部屋）：ワイン色のダマスク柄の壁紙、深緑の羽目板の腰板と木の手すり、寄木（ヘリンボーン）の床、張り出しの上げ下げ窓（ベイ）、黒ずんだ梁の天井、真鍮のガス灯、煉瓦のマントルピースの暖炉、ガラス入りの木の間仕切り、ペルシャ風の敷物、ヴィクトリア調の家具（`theme82.js` の magicka_city）。
- 用途の違い：宿は奥の受付と客室（寝台の列）、酒場はカウンターと瓶の棚・高い背もたれのブース席・暖炉、民家は居間と寝室の 2 区画、道具屋は引き出しと瓶の薬棚。
- 外観：煤けた赤煉瓦の壁・暗い石畳・真鍮の街灯・深緑と灰の屋根（`TOWN_EXT82.magicka_city`）。城下町の北の端の魔導王宮は楼門になり、扉の先が新しい城郭区画（§3.3）。
- 画像：`docs/images/v82/magicka_london_before_after.jpg`（改修前と後）。
- 注意：低画質（スマホの既定）の画像では、改修前（明るい木の床と白い壁）より暗い（暗い木の床・ワイン色の壁・ガス灯の暖かい光）。床の色と、低画質で上げるまわりの光を調整して、床と家具は読めるようにしたが、明るさは前より落ちた。高画質（PC の既定）と実機での見え方は確かめていない。

## 追記：飛空艇に乗れない不具合の修正（2026-11-07 21:24 の依頼）

- 症状：3D 版で、陸に止めてある飛空艇のマスへ歩いても（馬車でも）乗れない。2D 版は乗れる。
- 原因：2D 版は「乗り物のマスへ進む＝乗る」（`World.tryMove` → `Vehicle.resolveMove`）。3D 版の自由移動は、ぶつかって進めないときだけ `tryMove` を呼ぶ（`GameBridge.bump`）。水の上の船は水のマスでぶつかるので乗れていたが、陸（草地など）に止めた飛空艇はそのまま通り抜けてしまい、乗る処理が呼ばれなかった。陸に止めたアストラ号（「飛び立つ？」）も同じ。v8.2 より前（3D の最初の版）からある不具合で、v8.2 の改修では変わっていない（`bump` の処理は v8.2 の開始時と同じ）。
- 直し（3D だけ。2D 版・セーブは変えない）：`three-src/src/bridge/GameBridge.js` の `vehicleBlocks`：乗っていないとき、止めてある乗り物（陸の飛空艇など）とアストラ号のマスを、3D の当たり判定でふさぐ（いま立っているマスは除く＝着陸した直後は動ける）。ぶつかると `bump` → `World.tryMove` で 2D 版と同じに乗る／「飛び立つ？」を聞く。`MapScene3D.resolve` に、ほかにふさぐマスを渡せるようにした。
- 確かめ（ヘッドレス Chromium・3D 版・マクディアの飛空艇の家のそば。`docs/tools/v82/browser/airship82.js`・`docs/arch82/logs/3d/airship_board_result.json`）：
  | 場合 | 直す前 | 直した後 |
  |---|---|---|
  | 歩いて飛空艇へ | 乗れない（マスを通り抜けた） | OK（乗った） |
  | 馬車で飛空艇へ | 乗れない | OK（乗ると馬車は使わない状態になる。降りるとまた馬車） |
  | 決定キーで着陸 → 1 歩離れる → 飛空艇のマスへ戻る | （乗れないので試せない） | OK（着陸した直後は動けて、戻ると乗った） |
  | 陸に止めたアストラ号へ歩く | 「飛び立つ？」が出ない | OK（出た） |
  | 岸から水の上の遠洋航海船へ | （前から乗れる） | OK（変わらず乗れる） |
- 未検証：実機（スマホのタッチ操作・スティック）での操作。2D 版は変えていない。

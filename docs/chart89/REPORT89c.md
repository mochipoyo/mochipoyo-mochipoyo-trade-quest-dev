# v8.9 スマホでチャートが上下につぶれて見づらい — 修正の報告

ブランチ：`feature/chart-height-20261109`（`feature/perf-mobile-20261109` の 22e1a5a から。dev リポジトリだけ。main・本番には出していません）

## 1. 原因
| 画面 | 以前のスマホの高さ | 原因 |
|---|---|---|
| 修行場の試練・チャートの試練（`TradeUI.trial`）・相場の試練（簡易） | 160px（ローソク足の段は約 80px） | `@media (max-width: 720px)` で `.trade-panel .chart { height: 160px }`。下の 5 つの問題を見るためにスクロールすると、チャートは画面の外へ出ていた |
| 注文設定のチャート | 150px | `.mini-chart` の固定の高さ |
| チャートバトル（必殺技・修行・試験・トレードバトル）の横向き | **90px** | 横向きのスマホでは、ゲーム画面の幅（約 500px）の中に、見出し・時間・指標の切り替え・ボタンを縦に積んで、残りがチャートだった |
| 振り返り（2 枚のチャート） | 165px | 固定の高さ。下のチャートバトルの文字が透けて読みにくかった |
| クイズモンスターのチャートの問題 | 140px（横向き 130px） | 操作パネルの上の狭い枠の中。選択肢はスクロールの下に隠れていた |
| トレーディアのレバレッジ | 220px | 固定の高さ・操作パネルの上の狭い枠 |

## 2. 変えたこと（PC の広い画面は今までどおり）
- **縦向きのスマホ**：チャートの高さを画面の高さに合わせる（`svh`＝ブラウザのバーを除いた高さ。使えない端末は `vh`）。
  - 試練：画面の高さの 40%（220〜380px）。**時間足のボタンとチャートを画面の上に残したまま、下の問題・ボタンだけをスクロールできる**（`js/ui/trade.js` で、時間足のボタンとチャートを 1 つの枠 `.trade-chartwrap` にまとめた）。
  - 注文設定 32%（200〜280px）・振り返り 30%（190〜260px）・クイズ 24%／線のチャート 30%・レバレッジ 36%。
  - チャートバトル：指標の切り替えのボタンを 1 行（横にスクロール）にして、チャートに高さを回す。チャートの最低の高さ（画面の 34%）を決め、入りきらない小さい画面ではパネルをスクロールできるようにした（以前は下が切れる作り）。
- **横向きのスマホ**：チャートの画面（チャートバトル・試練・振り返り・クイズ・レバレッジ）は、横幅いっぱいに使う（`js/ui/mobile.js`。左右の操作パネルは、v8.8 から学習の画面では隠れている）。
  - チャートバトル・試練：**チャートを左、問題・ボタン・結果を右**に並べる。右側が長いときは右側だけを読み進めても、チャートは左に残る。
  - クイズのチャートの問題：問題文を上、チャートを左、選択肢を右。問題を解いている間だけ、モンスターの絵の帯を隠してチャートに高さを回す（名前は上に出ている）。
- 操作パネルを隠して画面を広く使う画面に、クイズモンスター（`.quiz-battle`）・トレーディアのレバレッジ（`.lev-panel`）を足した（以前はチャートバトル・試練・振り返りだけ）。
- 振り返りの窓だけ透かさない（チャートバトルの上に重ねて出るので、下の文字が透けて読みにくかった）。ほかの窓の透け具合（v8.x のご指示の約 10%）はそのまま。
- `js/ui/quizbattle.js`：チャートのある問題のときに、パネルに `qb-haschart` を付ける（見た目の切り替えだけ）。

## 5. 確認済み・推測・未確認
- **確認済み**：上の数（ヘッドレス Chromium でスマホの画面の大きさを再現して測った値）。PC の高さは変わらない。ボタンが隠れない・はみ出さない。通しの操作で問題なし。
- **推測**：iPhone の Safari ではアドレスバーの出し入れで見える高さが変わるため、`svh`（バーが出ているときの高さ）に合わせています。バーが隠れたときは少し余白が出る可能性があります。
- **未確認**：**実機（iPhone・Android）での見え方・スクロールの感じは確かめていません。** 特に、縦向きの試練で「チャートが上に残る」動き（position: sticky）と、横向きで画面いっぱいに広がる動きは、実機で一度見ていただく必要があります。

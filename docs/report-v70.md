## 2. 一部だけ／未実装

- **町・城・ダンジョンを広くする・2階3階を足す**：未実装（「全体を少しずつ」の次の段階）。今回は既存の地図の広さのまま
- **トレディアの「地上からエレベーターで行ける空の高い場所」**：遠景（見た目）だけ。乗れるエレベーター・空の区画のマップは未実装
- **ダンジョンの広い道**：通路の壁が1マスの厚さしかない迷路（多くのダンジョン）は、広げると抜け道ができるので広げていない（126のうち14）。広い道を増やすには地図そのものの作り直しが必要
- **場所ごとの個性**：3D 版の飾り（仮3D・箱や円柱の組み合わせ）。2D 版の地図の見た目は、階段・目印・海のきらめき以外は変えていない。近未来の建物はトレディアなど4つの町だけで、ほかの町の建物は今までの木組みの家（色・屋根は場所のデザインのまま）
- **フィールドの個性**：足もとの小さな飾り・光る模様だけ（地方ごとに最大90個）。大きな建物・地形の変更はしていない
- **半円の光**：画面で見えたものから原因を推定して直した。ご覧になったものと同じかは、実機で確認が必要

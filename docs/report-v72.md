## 2. 一部だけ／未実装（正直に）

- **新しい地区は、共通の型から自動で作った**：大通り・広場・塔・家・集会所の並びはどの町も同じ型で、建物の名前・言葉・床の材料・木の種類などを町のテーマ（王都・港・鉱山・砂漠・氷など17種）で変えている。町ごとに一から描いた地区ではない
- **人の言葉**：テーマの言葉を入れた共通の文（町の名前・塔の名前・見える景色などが町ごとに変わる）
- **城を広げる**：城の1階の形（廊下・部屋の並び）は描き直していない。上の階と別の部屋を足した。王都の王宮1・2階（ダンジョン）と魔王城は変えていない
- **2階を足せなかった所**：氷港シエルの港の建物（階段を置ける空いた床がない）。町ごとの2つ目は別の建物にした
- **ポヨ村**：v7.1 で東へ広げて2階3階を足したので、今回は変えていない
- **3D の見た目**：新しい建物は今までの汎用の家（近未来の町はガラスの建物）。塔だけ専用の形。実機での重さは未検証

### 作り直しの決まり（js/rpg/mapremake.js の冒頭に詳しく）
- 元の1マス → 2×2。通れない所は4マスとも通れない（元で通れなかった所が通れるようにはならない）
- 壁の縁は「削ったマスのとなりの床が元の床で、元の地図でたがいに4歩以内」のときだけ1マス削る（削ったマスどうしはつながらない）＝遠回りを省く近道・抜け道はできない
- 出来事（関所・鍵の扉・紋章の扉・試練の扉・隠し通路・調べる物・石碑・ボス・落とし穴）は 2×2 の4マスに置く（同じフラグで一緒に開く＝脇をすり抜けられない。どのマスでも同じ出来事。ボスの姿は1つ）
- 宝箱・松明・灯籠などの1マスの物：元の地図でふさいでいた道は、横に岩・茂みなどを置いて同じようにふさぐ（どちら側からも開けられる・調べられる）
- 出入口（ワープ）は1マス（地図の端の出口は端に面したマスすべて、壁の中の隠し通路は4マス）
- 座標：作り直したマップの中の物は新しい座標に書きかえた。作り直したマップ「へ」行く座標（ワープの行き先・物語の台本・ナビの「ev:マップ:x,y」）は旧座標のまま書き、World.enterMap が新しい座標に直す（向きつきなら、その向きの先に面したマス）。新しい座標で入るときは `World.enterMap(id, x, y, dir, { raw: true })`
- 歩く距離が2倍になるので、作り直したマップの敵の出る確率は半分（同じ道のりで出会う回数は今までと同じくらい）。v7.0 の「広い道」（MapWiden）は当てない

### セーブの互換
- 作り直したダンジョンの中で保存した古いセーブは、読み込むときに「いる場所」と「ミニマップの探索済み」を旧座標から新しい座標（2倍）に直す。直したことは `State.data.remakeVer` に記録（2回は直さない）。セーブのほかの中身は変えない
- ポヨ村は元の座標を変えていないので、そのまま
- 2D 版と 3D 版のセーブの保存場所（LocalStorage のキー）は変えていない

### 見つけて直した不具合（v7.0 で入ったもの）
- **v7.0 で push 済みの版の不具合**：3D 版の「近未来の建物」（トレディア・演算都市ノード・第7居住区・ラックスベル）が、変数の書き損じ（`H` が未定義）で作れず、木組みの家に戻っていた（v7.0 の報告では「近未来の建物にした」と書いたが、v7.0 の push 版では実際には出ていなかった）。直して、ガラスと金属の建物が出ることを確かめた。v7.0 の確認テストがこの警告を拾えていなかったので、拾うようにした

## 2. 一部だけ／未実装（正直に）

- **町・城を広くする・2階3階を足す**：今回はポヨ村（と空の区画の新しいマップ）だけ。リヴェルの城下町・城、ダウの村など、物語の順で次の町・城はまだ（次の段階）
- **ダンジョンの作り直し**：126のうち30。残りは、もともと通路が広いもの（幅1の通路が全体の15%未満）・小さな部屋・時限の仕掛けや氷の床がある階（凍結時計塔など。座標で動く仕掛けを壊さないため）。ダンジョンに新しい階（2階・3階）は足していない
- **作り直しのやり方**：手で一から描き直した新しい形ではなく、元の道順を保ったまま「2倍の細かさにして、縁を削り、飾る」作り直し（物語・仕掛け・宝箱・セーブを壊さないため）。参考画像のような「溶岩の川」「地底の水路」などの大きな地形は、通れる所を変えない範囲（小さな泉など）だけ
- **3D の飾り**：形は箱・円柱・円錐などの組み合わせ（仮3D）。専用に作り込んだのはポヨ村だけで、ほかは自動で置く飾り
- **実機での重さ**：飾りを大幅に増やしたので、スマホでの描画の重さは未検証（ヘッドレスのソフトウェア描画では、ダンジョンを組み立てる時間は約1〜8秒）

## 0. 仕組み（全拠点で共通）

- **有効な地図は 1 つ**：`Remake81.define(id, spec)` が `MAP_DEFS[id]` の `rows`・建物・人・出来事・宝箱・ワープを書きかえる（2D・3D・ミニマップ・人の歩き・仲間の追従は同じ GameMap を使う）。
- **適用の順**：`expand72-towns`（増築）→ `towns76`／`envlayout`／`interior76`／`homes73` → **remake81**（いちばん最後）。作り直した地図は `noLayout`・`noWiden` にして、`auto76`・`levels76`（作り直しで指定しないとき）・`plan76`・`edgeExits` を消す＝**後段の共通配置で専用設計が戻されない**。
- **旧座標 → 新座標**：`MapRemake.maps[id]`（`r81.N`）。旧セーブの位置・探索済みの印・調べる所（SEARCH_POINTS）・クイズの魔物・物語の台本・ナビの座標は、ここで一度だけ写す（`mapPos`・`fromPrev`。前の広げ（`i76.1` など）の上に重ねる）。
- **建物の扉**：建物の扉のワープは GameMap が作る。中の地図の出口の着く所は、新しい扉の前（自動）。**作り直した町では、中の地図で着く所が出口（扉）の上になる建物は 1 マス内側に着く**（`js/core/map.js`）。
- **「元の間取り」設定**（`EnvLayout.enabled === false`）のときは作り直しを使わない（前の間取りのまま）。
- **段（高さ）**：`spec.levels` で `levels76`（`js/rpg/terrace76.js`）を持たせる。段の縁は擁壁（`|`）、つなぎは階段（`/`）・坂（`;`）。3D は `Terrace3D` が高さを作る。
- **3D の部品**（`three-src/src/world/`）：`Furniture81`（的・炉・道具かけ・天球儀・黒板・計器・子午線）、`Arcade81`（渡り廊下・回廊・側廊・**弧の日陰回廊 ring**）、`Crest81`（紋章の盾と垂れ幕）、`variants76` の `observatory81`（観測塔）。光は炉と天球儀だけ。
- **初めて入ったときの見せ場**（3D）：`Remake81.firstView(id, flag, cine, ms)`。フラグで 2 回目からは待たせない。

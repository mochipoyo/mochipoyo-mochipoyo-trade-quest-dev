# v8.5 戦闘：ボスの名前は最初だけ表示する

依頼（2026-11-08）：ボスのイラストにボスの名前が重なるので、ボスの名前は最初だけ表示し、戦闘中は表示しない。

## 1. 変更（`js/ui/battle.js`。2D 版・3D 版の共通の戦闘画面）

### ボスの名前（敵の絵の上の文字）
- **表示する間**：登場の演出（暗転からせり上がる・カットイン）の間と、そのあと **4 秒**。続く 0.6 秒で薄くして消す。
- **戦闘中**：ボスの名前は表示しない。
- **数える時計**：実際の時計（`Date.now`）。戦闘画面の時計（`scene.t`）は、コマンドを選ぶメニューが上にある間は止まる。そのため戦闘画面の時計で数えると、最初のコマンドを選ぶ間ずっと名前が出たままになる。
- **状態異常・弱点露出があるとき**：その短い表示だけ出す（例：「弱点露出［毒］」）。名前は出さない。
- **名前が変わったとき**（変身など）：また最初から 4 秒表示する。
- **ボスとみなす敵**：敵のデータで `boss: true` の敵と、ボス戦の 1 体目。
- **ボス以外の敵の名前**：今までどおり、ずっと表示する。
- **変えていない所**：対象を選ぶ一覧・戦闘のメッセージ・敵の HP バー（設定）の表示。
- **長さを変えるとき**：`BOSS_NAME85 = { show: 4000, fade: 600 }`（ミリ秒）の数字を変える。

### あわせて直した、もとからあった問題：登場の演出が途中で止まる
- **起きていたこと**：登場の演出とカットインは、戦闘画面がいちばん上にあるときだけ進む作りだった。演出の途中で最初のコマンドのメニューが開くと、演出がそこで止まる。その間、画面中央のボスの名前の帯（「— 名前 —」）が半分の濃さで出たまま、暗転も少し残る。
- **確かめた事実**：この作業環境の 3D 版では、1.4 秒の演出のうち 1.3 秒の時点でメニューが開き、10 分たっても演出が終わらなかった（`logs/entrance85_3d.log` は直した後の記録）。
- **直し方**：戦闘画面がいちばん上でない間は、描くときに実際の時計の分だけ演出を進める。進め方は update と同じで、1 回 100ms まで。
- **推測**：実機でも、最初のコマが遅い端末（スマホ・3D 版の舞台を組み立てる最初のコマ）では起こりうる。実機では確認していない。

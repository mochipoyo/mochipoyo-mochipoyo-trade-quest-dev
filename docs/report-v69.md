## 7. 残っている課題

1. 家族・徴税官・黒い影の魔物・財団本部・波形聖堂の**専用の3Dモデルは未制作**（既存モデルの流用＝仮素材）。Blender のある環境での制作が必要
2. **実機（スマホ・GPU のある PC）での確認が未実施**。とくにスマホ縦画面での長い会話・イベント用カメラ・炎の点光源の重さ
3. 会話の文章は自動テストで発生を確かめただけで、文字の見切れ・読みやすさは人の目で未確認
4. プロローグ専用の BGM・環境音（炎・風）は未制作
5. 第4章のガルドの告白は、ガルドの加入が第5章のため、港の会話は第5章以降の一言になる（`docs/story-3121-conflicts.md` #7）
6. 祖先レオン・アレナ、お守りの由来、伝承のもちぽよの正体は、意図して確定していない（続編・隠し章の余地）
7. 波形聖堂の試練の実際のチャート画面での遊び心地は未確認（採点の結果をテストで代用）
8. 3D の各章の追加イベント（第1〜15章）は 2D の処理でだけ確認（3D でも同じ処理が動く作りだが、画面では未確認）

## 2. 戦闘背景（砂漠の誤り）

- `js/ui/battlebg65.js` の `placeOf`：フィールドで出現地帯の名前に「荒野」があると `desert` を返していた。アルカディアの「南の荒野」（草地・砂浜・岩山のまじった土地）で砂漠の絵になっていたのはこれ
- 直したあと：砂漠の絵になるのはリシア砂漠の地域（フィールド・町・砂嵐の回廊など）だけ。全マップ・全出現地帯で確かめ、砂漠の地域以外で砂漠の絵になる所は 0
- 「荒野・荒地・山脈・山地」の出現地帯（南の荒野・エマール山脈・グラニアの鉱山地帯・断裂群島の廃墟側の荒地・時の神殿領の神殿の山地）は、草原の代わりに岩場と山の差分画像（`15_battle_grassland_mountain.webp`）
- 3D版の戦闘の地面・飾り（サボテンなど）も同じ判定を使うので、3D版でも砂漠の飾りは出なくなる

## 3. 生活・健康の豆知識おばさん（`js/data/chatter67.js`・`js/rpg/chatter.js`）

- 24の町に1人ずつ（例：ポヨ村のマーサおばさん）。見た目は既存の町の女性の絵（`villager_f`）
- 豆知識は37種類：手洗い・水分と塩分・睡眠と光・朝の光・肉の加熱・作り置き・座りっぱなし・重い物の持ち方・歯みがき・換気・よくかむ・塩分・お酒と判断・寝不足と判断・家計の記録・蓄え・置き場所・洗濯・目の休め方・手すり・やけど・切り傷・休むこと・野菜、地域ごとに雪道・ぬれた手袋・凍った湖・砂漠の夜・日差し・冷たい海・火山のガス・鍛冶場の暑さ・高い所の風と日差し・ほこり・食事と睡眠・不安を話すこと
- 内容は、厚生労働省などが一般向けにすすめている、よく知られた生活・健康の注意に限った。病気の診断や治療、薬の話はしない。3回に1回「具合が悪いときは、無理をしないで、ちゃんと診てもらうんだよ」と添える
- 置き場所：周りが広く空いていて、出入口・NPC・宝箱・イベント・調べる場所と重ならないマス（テストで24人すべて確認）

## 4. 町の人の会話（3種類の別の会話）

- **対象**：町人・老人・子ども・兵士・商人・学者・船乗り・店の人・神官の見た目で、会話の中で店・宿・仲間・戦闘などを動かさない NPC（258人）。仲間・師匠・王などの登場人物、店主として働く NPC、ゲームの仕組みを直接さわる会話は対象外（いままでどおり）
- **流れ**：①何かが起きる会話（フラグ・アイテム・クエスト・仲間のひと言）＝重要な会話はいままでどおり → ②いつもの会話を1回 → ③話しかけるたびに「その地域の話」「その人の話」「相場の小話」→ ④いつもの会話に戻る。物語が進んで、いつもの会話の中身が変わったら、また②から
- **しくみ**：本物の会話の前に、記録だけする「下見」をして、状態を変える呼び出しがあれば重要な会話とみなす。下見はゲームの状態を何も変えない（全258人で確かめた）
- **文**：地域ごとの暮らしの話（12地域・8〜10種類ずつ）、見た目ごとの話（9種類・5〜8種類ずつ。老人は「〜じゃ」、子どもは子どもらしい話し方）、相場の小話（24種類。もちぽよ手法の範囲と一般的な資金管理のうわさ話の形）。同じマップの町人には、なるべく別の文が当たる
- **注意**：最初の重要な会話がない町人は、いつもの会話を1回聞いたら、次から別の会話になる（「重要な会話」と「いつもの会話」が同じ中身のため）
- **セーブ**：`d.chat`（町人ごとの小さな記録）。古いセーブにはないので、なければ作る

## 8. 追加の修正：3D版の戦闘でボスが以前のデザインに戻る（2026-11-02 17:03 のご報告）

### 原因（作業環境で再現して確認）
- v6.6 で「スマホで敵が味方の手前に出る」問題を直したとき、**敵の絵を3D（WebGL）で使えない場合に、その敵の簡易の絵（コードで描く以前のドット絵）で3Dに立たせる**ようにしていた（`BattleActors3D.js` の `altVisual`）
- テストプレイの配信（githack など）でボスの新しい画像が「別のサイト扱い」になり、ボスの絵のキャンバスが読めない（WebGL に渡せない）と、この簡易の絵＝以前のデザインに切り替わっていた。ご報告の欲望のゴーレムの絵は、この簡易の絵と一致した
- もう1つ：戦闘の始めにボスの新しい画像が間に合わず、以前の絵で3Dの立体を作ったあと、新しい画像に切り替わっても3Dで使えないと、**以前の絵の立体が残り続ける**ことがあった

### 直したこと
- `js/core/bossart.js`：ボスの画像を、まず CORS（crossOrigin）で読む（読めないときは従来どおり読み直す）。別のサイト扱いの配信でも、ピクセルを読めるキャンバスになる。
  さらに `BossArt.cleanVisual(id)` を足し、読めないキャンバスのときは、同じ画像を CORS つきの別の URL で読み直して同じ加工をする（通常の敵の `EnemyArt.cleanVisual` と同じ方法）
- `three-src/src/battle/BattleActors3D.js`：ボスの絵が3Dで読めないときは `BossArt.cleanVisual` で読み直す。それでも使えないときは、**以前の簡易の絵には替えず**、2D版が新しい絵を3Dの立ち位置（味方の奥）に描く。2D版の絵が新しい画像に切り替わったのに3Dで使えないときは、前の絵の立体を消す。通常の敵も同じ（以前の簡易の絵は使わない）
- `three-src/src/world/MapScene3D.js`：マップのボスのシンボルも、読めないときは同じ方法で読み直す

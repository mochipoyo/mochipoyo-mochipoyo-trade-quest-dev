## 4. 用語

- **均衡暦**：大災害（西暦3024年）を0年とする、いまの人々の暦。住民はふつう均衡暦を使う
- **西暦**：旧時代の数え方。古い記録・旧地球の発見で出てくる
- **旧時代**：2052年より前の文明。村では、錆びない金属・透明な板などの遺物を日用品に使っている
- **魔災復興税**：カリオン徴収連邦の特別徴収（既存）。アサナ村では収穫の四割
- **第三復興事業**：アサナ村などの税と財団の復興基金が支出されたことになっている、実在しない事業
- **抹消台帳**：カリオン財務局が「魔物被害により全滅」とした村を徴税台帳から消した記録（11村）
- **波形トレーダーズビルド**：伝承上の学びの場の名。財団と波形教の共通の源とされる
- **相場盤**：木の実などを賭ける、遊びの相場。判断の理由を言えた方が勝ち
- **千年の記録帳**：旅で見つけた古い記録の写し（ゲーム内の図鑑。重要アイテム）

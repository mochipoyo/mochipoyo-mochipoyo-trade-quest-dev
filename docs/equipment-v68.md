# 装備の段階づけ（v6.8・2026-11-03）

ご要望：「各地で売っている装備アイテムにあまり違いや強さの差がないので調整する（地域が進むごとに強くするなど）」

## 方針

- **足すだけ**：既存の装備（`js/data/items.js` など）の値・値段・店の品ぞろえ・入手先は変えていません。消していません。
- 地域ごとに「その地域でいちばん強い剣の攻撃力」「いちばん強い鎧の守備力」の目安を決め、店が売っている種類のうち目安に届かないものだけ、その地域の新しい装備（シリーズ名つき）を足しました。
- 実装：`js/data/tweaks68.js`（`EQUIP_TIER68`）。店への追加は既存の仕組み `SHOP_ADD[店のマップID]`（`Services.addedStock`）を使っています。
- 種類ごとの比（剣＝1）：槍 0.97・斧 1.04・弓 0.97・短剣 0.84・杖 0.74（＋魔力）・槌 0.94（＋魔力）・爪 0.90。
  防具（鎧＝1）：軽鎧 0.86・法衣 0.82・盾 0.75・兜 0.42・帽子 0.30。
- 値段：武器は「3×攻撃力²」、防具は「5×鎧の目安²×比」を目安に100G単位（既存の装備の値段とだいたい同じ線）。
- 灰灯島（断裂群島）には防具の店がないので、交易商人（`aruna_village`）に防具もひとそろい並べました。
- アルカディア・グラニア・カリオン・マクディアの店は変えていません（もともと段階がついていたため）。
- 相場都市トレディア（v6.8 でマクディア地方へ移動）の店の品（トレード系の装備）は変えていません。マクディアの店よりは弱めです。

## 確認

- 2D版の自動テスト `tweak68test.js`（作業用フォルダ）：76種がそろうこと、名前の重複がないこと、地域の順に剣の目安が上がること、新しい装備がどれかの店の追加分（`SHOP_ADD`）に入っていること、鐘都テンプスの武器屋（`Services.addedStock`）にその地域の装備だけが並ぶこと、既存の装備の値・値段と店の `stock` が変わっていないこと（代表の4種・4店）。
- 実際の戦闘の手ごたえ（敵の強さとの釣り合い）は、遊んでの確認が必要です（未検証）。

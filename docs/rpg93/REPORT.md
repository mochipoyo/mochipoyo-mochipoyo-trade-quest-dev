## 3. 仲間ごとの作戦

- 作戦は **オート戦闘** のときの考え方（手動のときは今までどおり自分でコマンドを選ぶ）。最初はみんな「バランスよく」＝今までのオート戦闘と同じ動き
  - バランスよく：蘇生・回復（HP45%未満）・治療と攻撃を状況で選ぶ（今までと同じ）
  - ガンガン行く：MP を惜しまず強い攻撃・全体攻撃。回復はピンチ（HP25%未満）のときだけ。状態異常の治療は後回し
  - 回復重視：HP70%未満で回復。攻撃に MP を使わない
  - MPを使わない：MP を使う呪文・特技は使わない（通常攻撃と MP0 の技だけ）
- 変える場所：メニュー → なかま →「さくせん」（仲間ごと・「みんな同じ作戦にする」）／戦闘のコマンド「さくせん」（右に今の作戦）
- セーブ：仲間ごとに `tactic` を持つ（前の版のセーブは「バランスよく」）
- スマホ縦画面：コマンドが 8 行になったので、行を少し詰め（高さ 44px → 36px）、窓を味方の欄の上に収めた（スクロールなしで全部見える）。スマホ横画面は今までどおり窓の中でスクロール

## 4. まんたん

- メニュー → なかま →「まんたん」：足りない HP の合計を見せて「呪文と道具で回復する／呪文だけで回復する／やめる」
- 呪文：戦闘メンバーが覚えている回復の呪文から、**MP あたりの回復が大きいもの** を選んで繰り返す（全体回復は効く人数で比べる）。回復量は戦闘中と同じ式（戦闘だけの効果は入れない）。沈黙の仲間は唱えない
- 道具：HP だけを回復する消費アイテム（MP も回復する・食事・全回復・蘇生・状態異常の治療の道具は使わない）。足りない量にいちばん近いものから
- 戦闘不能の仲間は回復しない（「教会か蘇生の呪文で」と出す）。結果は「〇〇は△△を n 回唱えた（MP−x）」「薬草を n 個使った」の形で表示

## 5. 効き目の表示・会話の履歴

- 効き目：呪文・特技の一覧の説明に「◎ばつぐん：敵の名前」など、対象の一覧の右に「◎ばつぐん／△いまいち／×きかない」と色。倍率は実際のダメージの計算と同じ（敵の属性の耐性）。状態異常・弱体の技はボスに「いまいち」（ボスは 60% で防ぐため）。設定「呪文・特技の効き目の表示」で消せる
- 会話の履歴：会話・説明・選択肢（問いと選んだ答え）を新しい 300 件まで。会話の窓の［履歴］ボタン・↑キー・メニュー（冒険 →「会話の履歴」）で開く。場所の名前で区切って表示。セーブには入れない（遊んでいる間だけ）

## 6. BGM

- 曲：オープンソースのゲーム「0 A.D.」（Wildfire Games）の音楽 36 曲。ライセンス **CC BY-SA 3.0**（表示・継承）。入手元は GitHub の 0ad/0ad（コミット `61a3b95…`）。Ogg を MP3（64kbps）に変換しただけで、曲の中身は変えていない。合計 約 46MB（`assets/music/`）
- クレジット：`assets/music/CREDITS.md` とゲームの中（設定 → 音 →「BGM のクレジット」）。**CC BY-SA の条件（作者名・ライセンス名と URL の表示、曲を改変して配るときは同じライセンス）は、公開するときも守る必要がある**
- 割り当て（`js/data/bgm93.js`。表を書き換えるだけで差し替えられる）
  - 町：35 の町・村ごと（決めていない町は 5 曲から町の名前で決まる）。城・教会・酒場は専用の曲。家・店・宿屋の中は外の曲のまま
  - フィールド：地方ごと 15 ＋ 地球の配置の地方は名前で 8（海・大洋は海の曲）。船＝海の曲、飛空艇＝空の曲
  - ダンジョン：5 曲から、ダンジョンごとに決まる（**ダンジョン 1 つに 1 曲ずつではない**。同じダンジョンの中は階を移っても同じ曲）
  - 戦闘：通常（前半／後半の地方で別の曲）・ボス・ボスの部屋。タイトル・エンディング
  - サウンドテスト：設定 → 音 →「BGM を聞く」
- 曲の選び方：0 A.D. の中での使われ方（平和な場面・戦闘・メニュー）・曲名・テンポや音量の測定で選んだ。**耳で聞いて選んだのではない**ので、雰囲気が合わない曲があるかもしれない（差し替えは表の 1 行）
- 鳴らし方：`<audio>` で流し、0.8 秒で重ねて切り替える。戦闘のあとは町・フィールドの曲の続きから。**音を消している間は曲を読み込まない**（通信量を使わない）。曲が読めないとき・設定「BGM の種類＝レトロ」のときは今までの自作の電子音の BGM
- タイトル：［♪ 音：OFF/ON］を追加（2D・3D）。最初は今までどおり音なし。ON にするとタイトルの曲が鳴り、そのまま「はじめから」のゲームも音ありで始まる
- 直した不具合（作業中に見つけたもの）：タイトルで音を ON にしたとき、同じ曲が 2 つの再生器で重なって鳴っていた → 同じ曲なら今の再生器のまま

## 7. 戦闘の演出・効果・モーション

演出のデータ（`js/data/fx65.js`：全部の呪文・特技に「演出の種類・動き・色」）と時刻表（命中の瞬間）は今までのまま、その上に描く層（`js/ui/fx2d.js` の Rich）を足した。命中の瞬間・ダメージの数字・HP の変化は今までどおりそろう。

- 構え：呪文・祈り＝使う人の足もとに回る魔法陣（呪文は星、祈りは花の形）と光の柱、まわりから光の粒が集まる。雄たけび＝広がる輪。武器の技＝刃のきらめき。大きな攻撃呪文（全体・大技）は、構えの間まわりを少し暗くする
- 飛ぶもの（火の玉・矢・氷・闇の玉など）：光る玉と光の尾（炎・氷・闇・風は粒をこぼす）
- 命中：白い芯と色の光・足もとの衝撃波・属性ごとの粒
  - 炎＝火の粉と煙／氷＝氷のかけら・霜の六角／水＝しぶき／雷＝枝分かれしてちらつく稲妻と火花／風＝渦と葉／光＝放射する光の線ときらめき／闇＝吸い込む輪と紫の煙／回復＝光の柱・上る光の輪・＋／守り＝きらめき／強化＝↑と立ち上る光・弱体＝↓と影／時＝時の輪／お金＝金のきらめき／物理・チャートの技＝火花（重い一撃は土ぼこり）・刃の月形の跡（多段は向きを交互に）
  - 会心の一撃＝集中線ときらめき、弱点＝橙の輪
  - 重い一撃・大きな呪文・雷は画面が揺れ、大技の最初の命中で画面が一瞬その色に光る
- 敵の動き（2D の絵）：攻撃＝構えで少し引いてから、近づくように大きくなって踏み込む／呪文・祈り＝浮いて体が光る（技の色）／雄たけび＝ふくらんで光る／当たった＝反動（会心は大きく）
- 味方の動き（画面下の欄）：技の動きごとに 13 種類（振る・突く・振り下ろす・射る・投げる・殴る・ひっかく・駆ける・体当たり・唱える・祈る・叫ぶ・構える）。山は命中の瞬間ごろ。当たった＝赤く光る（会心は大きく揺れる）、回復＝緑、生き返る＝金
- 設定「戦闘の演出」：自動（はなやか。端末の「動きを減らす」のときは控えめ）／はなやか／控えめ（画面の揺れ・画面全体の光・暗くするのをやめ、粒を減らす）。粒の数は「戦闘背景の品質」にも合わせる（軽量は少なく）
- 3D 版：この演出の層は 3D の舞台の上にも描く（今までの 3D の粒・光の柱もそのまま）。PC の右下の小さな仲間の一覧は光るだけ（3D の体が動くため）。**3D の体の動き（攻撃・呪文のモデルの動き）は今までのまま**（モデルに新しい動きを付けるのは今回していない）
- 重さ（ヘッドレス Chromium・2D・ソフトウェア描画で、戦闘画面 1 枚を描く命令の時間）：〔fx93 の結果〕。**実機の GPU での重さ・フレームレートは測っていない**

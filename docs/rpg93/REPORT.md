## 3. 仲間ごとの作戦

- 作戦は **オート戦闘** のときの考え方（手動のときは今までどおり自分でコマンドを選ぶ）。最初はみんな「バランスよく」＝今までのオート戦闘と同じ動き
  - バランスよく：蘇生・回復（HP45%未満）・治療と攻撃を状況で選ぶ（今までと同じ）
  - ガンガン行く：MP を惜しまず強い攻撃・全体攻撃。回復はピンチ（HP25%未満）のときだけ。状態異常の治療はしない
  - 回復重視：HP70%未満で回復。攻撃に MP を使わない
  - MPを使わない：MP を使う呪文・特技は使わない（通常攻撃と MP0 の技だけ）
- 変える場所：メニュー → なかま →「さくせん」（仲間ごと・「みんな同じ作戦にする」）／戦闘のコマンド「さくせん」（右に今の作戦）
- セーブ：仲間ごとに `tactic` を持つ（前の版のセーブは「バランスよく」）
- スマホ縦画面：コマンドが 8 行になったので、行を少し詰め（高さ 44px → 36px）、窓を味方の欄の上に収めた（スクロールなしで全部見える）。スマホ横画面も窓を味方の欄の上に移し、行を詰めて 6 行見える（残りは今までどおり窓の中でスクロール）

## 4. まんたん

- メニュー → なかま →「まんたん」：足りない HP の合計を見せて「呪文と道具で回復する／呪文だけで回復する／やめる」
- 呪文：戦闘メンバーが覚えている回復の呪文から、**MP あたりの回復が大きいもの** を選んで繰り返す（全体回復は効く人数で比べる）。回復量は戦闘中と同じ式（戦闘だけの効果は入れない）。沈黙の仲間は唱えない
- 道具：HP だけを回復する消費アイテム（MP も回復する・食事・全回復・蘇生・状態異常の治療の道具は使わない）。足りない量にいちばん近いものから
- 戦闘不能の仲間は回復しない（「教会か蘇生の呪文で」と出す）。結果は「〇〇は△△を n 回唱えた（MP−x）」「薬草を n 個使った」の形で表示

## 5. 効き目の表示・会話の履歴

- 効き目：呪文・特技の一覧の説明に「◎ばつぐん：敵の名前」など、対象の一覧の右に「◎ばつぐん／△いまいち／×きかない」と色。倍率は実際のダメージの計算と同じ（敵の属性の耐性）。状態異常・弱体の技はボスに「いまいち」（ボスは 60% で防ぐため）。設定「呪文・特技の効き目の表示」で消せる
- 会話の履歴：会話・説明・選択肢（問いと選んだ答え）を新しい 300 件まで。会話の窓の［履歴］ボタン・↑キー・メニュー（冒険 →「会話の履歴」）で開く。場所の名前で区切って表示。セーブには入れない（遊んでいる間だけ）

## 8. 読み込みの速さ

### 8.1 変えたこと

- **JS を 1 つのファイルにまとめる**：今まで 2D 版は 252 個の JS を 1 つずつ読んでいた（3D 版も同じ 252 個＋3D の部分）。`tools/stamp-version.js` が版の印を付けるときに、同じ順番で 1 つにまとめて縮めた `dist/mtq.min.js`（esbuild。中身の処理は同じ）を作る。ページはまずこれを読み、**読めなかったときは今までどおり 252 個のファイルを読む**（`index.html` の `<template id="mtq-src">` が元の一覧。テストもこの一覧を使う）。元のファイルはそのまま
- **画像を WebP に**：効果のある 144 枚（PNG・JPEG。合計 13.2MB）に、WebP（非可逆の圧縮・品質 90。透明の部分は品質 100。合計 3.7MB）を並べて置いた。非可逆なので元の画像とまったく同じではない（見た目の差は細かく確かめていない）。WebP を表示できるブラウザは WebP、できないブラウザ・読めなかったときは元の画像（元の画像は消していない）。最初に読む画像（172 枚）は 4.11MB → 1.55MB。ワールドマップの画像・小さい画像（20KB 未満）・あまり縮まないもの（20% 未満）はそのまま（`tools/make-webp.py`）
- **Service Worker**（`sw.js`。https のときだけ。URL に `?nosw` で止められる）：初めて開いたとき、読み込みが終わって 3 秒後に、そのとき読み込んだファイル（曲を除く）を端末に保存する。2 回目から、版の印つきのファイルは通信せずに端末の保存を使う。通信を切っても、保存したものでタイトルまで開ける（https の確かめ用サーバーで確かめた）。ページ・`version.json` は毎回まず通信して最新を確かめる。版が変わると古い保存は消す。曲（MP3）は扱わない（ブラウザの通常のキャッシュ）。**セーブ（LocalStorage）には触らない**
- 3D 版：`three-src/vite.config.js` が 2D と同じ仕組み（まとめた JS・切り替え・Service Worker）を `3d/index.html` に入れる。作り直しの前後で `3d/` のファイルは 179 個で、変わったのは `main-*.js` の名前だけ（消えたファイルなし）

## 2. 遊ぶ人が感じる変化（Phase 別）

### Phase 1：共通の操作
- **一覧のタップ**：ふつうの一覧（メニュー・戦闘の行動・セーブのスロットなど）は **1 回タップで実行**。詳しく見てから決める一覧（どうぐ・そうびの候補・店で買う・転職・職業選び）は、1 回目のタップで選んで下に詳細、［使う・見る］［装備する］［買う］［この職業にする］のボタンか同じ行の 2 回目で実行。最初から選ばれている行も 1 回目は選ぶだけ。窓の下に「行をタップで詳しく見る → もう一度タップか［○○］で決定」と出る
- 使えない行はタップ・Enter でも実行しない（選んで理由を読むことはできる）
- 上に別の窓（確認など）が開いている間、下の窓の行・✕ はタップしても反応しない
- 一覧のカーソル位置・スクロール位置を覚える（どうぐのタブ・並び替えごと、設定のタブごと、メインメニューの分類ごと）
- **名前入力**：［やめる］ボタンと Esc。やめるとタイトルへ戻る（以前は勝手に「勇者」で始まった）。空のまま決定は今までどおり「勇者」
- **中断の確認**：最初のカーソルは「続ける」。Esc も続ける
- **セーブ**：データのあるスロットへは「上書きする？」と確かめる
- **メインメニュー**：冒険／パーティ／どうぐ／トレード／システムの 5 つのタブ＋上に［どうぐ］［そうび］［目的地］［セーブ］のボタン（1 回で開く）。項目の名前は今までと同じ。「ワールドマップ」「回復の道具」「最近使った・お気に入り」「重要アイテム」「トレード成績・振り返り」「データ管理」「タイトルに戻る」を足した。窓の大きさは項目の数で揺れない
- **どうぐ**：［★お気に入り］で印、［★最近・お気に入り］で絞り込み（最近 8 個まで。使えたときだけ記録）。使う相手の一覧に「HP あと○」、いちばん減っている人に最初のカーソル
- **そうび**：候補を選ぶと HP・MP・攻撃・防御・素早さ・魔力・魔法防御の「いま → 装備後 → 差（▲▼）」、その下に属性耐性・状態異常・固有効果・装備できる職業を分けて出す。［おすすめ候補を見る］（攻撃重視・耐久重視・魔法重視）は一覧を見せるだけで、自動では装備しない（候補には ◎）
- **設定**：音／表示／操作／戦闘・トレード／データ管理のタブ。項目を選ぶと値の一覧（いまの値に ●）から選ぶ（押すたびに回る方式をやめた）。BGM・効果音は 0〜100%（10%刻み＋前の値）、効果音は選ぶと試しの音
- **文字の大きさ**「標準／大きい」（設定 → 表示）。窓・リザルト・チャートの文字と、チャートの価格の目盛りが大きくなる
- スマホの主な操作（一覧の行・ボタン・✕）は高さ 44px 以上

### Phase 2：チャートバトル
- **時間制限なしの練習**（修行で「初心者練習」を選ぶ）：［次の足へ］［再生／停止］でだけ足が進む。止めて分析できる。時間切れはない。決済の決まりは同じ
- **通常**（修行で「通常」）：設定の 20／25／30 秒。**試験・必殺技・対戦の時間は変えていない**（呼び出し元が時間の決まりを渡さないときは今までどおり）
- チャートの上に「モード（○秒）」、判断のボタンの下に「判断は 1 回。見送り＝入らない（時間切れも見送り）」
- 練習だけ、RCI・MACD・上位足・高値安値・印の表示を切り替えられる。試験は「表示の切り替えはできません」と出す
- **十字線**：PC はマウスを重ねる、スマホは長押し（0.45 秒）。その足の「○本前」・始値〜終値・EMA・RCI・MACD（見えている足だけ。未来の足は選べない）
- 価格の目盛りの文字 9〜10px → 11〜12px。情報の欄は省略せず折り返す
- **結果を 3 つに分けた**：①判断（買い・売り・見送り、時間切れか自分か、何秒・何回足を進めたか）②損益（pips・損益÷ATR）③判断の過程の評価（判断した瞬間の見立てと比べる。「負けても根拠に沿った判断」「勝っても根拠と逆」を書き分ける。見送りは「時間切れ／適切な見送り／根拠があった場面での見送り」を分ける）。振り返りのボタンを大きくした
- **戦闘中の簡易の相場の試練**：買い・売り・見送り → 理由 4 択 → 判定（行動 70＋理由 30 点。損益では採点しない）。詳細の成績・ランクには入れず別に記録。**ボス戦・修行場・学院・物語の試練は詳細のまま**。新しく始めたゲームは簡易、前からのセーブは詳細のまま（設定で切り替え）
- **トレード成績・振り返り**（メニュー → トレード）：ランク・苦手そうな分野・チャートバトルの成績・簡易の試練・続けて学習した日（日時が残る記録だけから数える）・おすすめの練習

### Phase 3：通常戦闘
- 行動の一覧に「**前回と同じ（〜）**」。選んだときに MP・道具の数・沈黙・対象の生死を確かめ直し、使えなければ理由を出して選び直し。前の相手が倒れていたら相手を選び直す。必殺技・にげるはくり返さない。最初のカーソルは今までどおり「たたかう」
- 特技に［★お気に入り］（先に並ぶ）。MP の足りない技は理由つきで選べない
- 戦闘の道具は、お気に入り・最近使ったものを先に
- オートのボタンに「次の戦闘も続く」。ボス戦の始めにオートが ON なら知らせる
- リザルト：通常の敵だけの勝利は簡単な表示。ボス・固有装備・レベルアップ・新しい技があると上に強調の帯。報酬の付与は今までどおり 1 回だけ
- 敵の HP バー：「はじめから」で新しく始めたときだけ表示を既定に（前からのセーブの設定は変えない）

### Phase 4：トレードマスター
- 相手は**決めておいた時刻**に、その時点までに見えている足だけで判断する（プレイヤーが早く決めても前倒ししない）
- 結果に「あなた／相手」の比べる表：判断・入った時刻（何本目）・入った価格・その時点の見立て・結果
- 3本勝負：「あなた ○ － ○ 相手・第○戦／2本先取」をチャートの上に常に出す
- 勝負のあとに記録（はじめての勝利・3本勝負の初勝利・相手ごとの初勝利・連勝と最高連勝）。**賞金・報酬は増やしていない**。400 歩の待ち・pips での勝敗は今までどおり

### Phase 5：スマホ・3D・経路
- 設定（操作）：スマホの操作ボタンの位置（左右の入れ替え）・濃さ・大きさ
- チャートバトル・相場の試練・振り返りの間は、スマホの操作パネルを隠し、縦画面では窓を画面の高さいっぱいに使う
- 3D 版の案内：人＝話す／宝箱＝開ける／ボス＝挑む／看板＝読む／ほか＝調べる。スマホは「決定」、PC は「Z」と出す
- 3D のカメラの設定・主人公の透けて見える表示・読み込みの表示は前からある仕組みを使い、変えていない

## 5. 判断した点・数字

- **トレードマスターの相手の判断の時刻**（Phase 4）：同じ場面・同じプレイヤーの判断で 600 場面ずつ比べた（`logs/tm88*.log`）。引き分けが約 62% → 約 49% に減り、勝ち・負けがともに増える。勝負がついた中でのプレイヤーの勝ちの割合は 54.8% → 52.4%（2D の読み込みでは 56.3% → 51.2%）。どちらかに大きく偏ってはいない。場面は毎回ランダムなので、数字は実行ごとに数ポイント揺れる
- **簡易の相場の試練の点数**：行動 70＋理由 30。既存の「60 点以上で敵の防御が崩れる」の決まりに合わせ、行動が合っていれば成功、理由だけでは成功しない
- 戦闘の演出の速さに「簡易演出」は足していない（今の「ふつう／はやい」のまま）
- R 倍数・判断の質で勝ち負けを決める新しい対戦の形式は足していない（今の pips の勝敗のまま）

## 6. 未確認・残る課題

- **実機**（iPhone・Android・タブレット・PC の GPU）での表示・タッチ・長押しの十字線・操作パネルの入れ替え：ヘッドレス Chromium のまねだけ
- **3D の fps**（PC 60fps・スマホ 30fps の目標）：**計測していない**。この作業環境の描画はソフトウェア描画で 1 秒に 1〜2 コマのため、目安にならない。3D の通しの確かめでは描画を止め、移動の処理を直接動かした
- クラウドセーブ：この環境から接続できないので確かめていない（保存の処理は変えていない）
- 人が実際に遊んでの手ざわり（1 タップの感じ・前回と同じの便利さ・簡易の試練の難しさ）
- 経路：v8.2 で NG と記録された 8 件は、どれも意図どおり（物語の鍵・出来事の入口）か、跳ね返らない「着いたマスがワープの上」で、地図は変えていない。ほかの経路の新しい確かめはしていない
- 既存の不具合（前からある）：ch1316test の 2 件のエラー（camp talk bonds undefined・sky record）と、オート戦闘で魔王に負けると終盤の確かめが続かないこと（v8.7 の報告と同じ）

## 1. 決めたこと

- **各地に50体**：12の地域すべてに置いた（アルカディア6・グラニア4・カリオン6・断裂群島4・リシア砂漠4・時の神殿領4・忘却の雪原4・ゼロメア4・マクディア4・竜炎火山群島3・天空群島3・暗黒大陸4）。既存の5体と合わせて55体
- **出題のしかた**：最初の5体は、いままでどおり専用の20問ずつ。追加の50体は「分野（cats）と難しさ（dmin〜dmax）」で、全205問（既存100問＋追加105問）から出題範囲を作る。範囲が8問に満たないときは難しさの範囲を1ずつ広げる。同じ問題を別のモンスターが出すことがある
- **正解の判定**：生成AIは使わない。問題・選択肢・正解・解説はデータに固定で書き、正解は「元の番号0」（画面では選択肢をまぜる）
- **エンジンの変更**：`Quiz.belongs(問題, モンスター)` を足し、出題・確定・途中の問題の確認で「その問題がそのモンスターの出題範囲か」を見るようにした（以前は「問題の持ち主が1体だけ」を前提にしていた）。最初の5体の動きは変わらない
- **報酬**：地域が進むほど大きい（その地域に来るころの想定レベルで、およそ0.5〜1レベル分の経験値。ゴールドの報酬は、間違えたときに奪われる上限より多い）。初めて倒すと称号と記念アイテム（大事なもの）
- **置き場所**：既存のマップの、通れるマス。NPC・宝箱・出入口・イベント・ボス・探索ポイント・師匠と重ならず、入口から歩いて行けて、ふさいでも行けなくなる場所が出ないマス（`ult/quiz_place_test.js` で55体すべて確認）
- **3D版**：これまで3D版ではクイズモンスターのシンボルが描かれていなかった（通れないマスとしてだけ働いていた）。2D版と同じ絵を立て札にして、光の輪と立ちのぼる「？」をつけて描くようにした

## 4. 画像（仮の画像）と素材の仕様

**追加の50体の画像は、コードで描いた仮のドット絵です（`js/core/quizmonart2.js`）。完成した素材ではありません。** 最初の5体のような1体ずつの専用の絵ではなく、11種類の体の形（blob・lamp・imp・bat・beast・crab・golem・bird・ghost・serpent・eye）× 19種類の紋章 × 色で描き分けています。

正式な画像に差し替えるとき（最初の5体と同じ方法）：
1. 透過 PNG：正方形（推奨 384×384 以上）、全身がキャンバスに収まり、上下左右に1割程度の余白、足元は下端の中央付近。待機の動きは、いまはコードで4こま（呼吸・まばたき）を描いている。PNG に差し替えると1枚の絵になる
2. `assets/quiz_monsters/quiz_monster_0NN.png`（NN は番号）に置き、`js/data/asset-manifest.js` に登録する
3. `QUIZ_ART_FILES.quiz_monster_0NN = 'assets/quiz_monsters/quiz_monster_0NN.png'` を書く。読み込めないときはコードの絵に戻る
4. 見た目の方向：名前・分野・紋章（表の「仮の絵」）に合わせる。例：ピプスライム＝目盛りのついたスライム、ロウソッキー＝ローソク足の燭台の精、リワード蟹＝右のはさみが左の2倍、エマ三兄弟＝三本の針の時計の騎士

## 3. 仕様（確定した基準と仮設定の区別）

確定した基準（ユーザーが共有した基準。v9.0 から変えていない）：上位足 日足・4時間足／エントリー足 5分・15分／EMA 20・30・40／RCI 9（±70 付近からの反転）／MACD 6・13・4／確定した高値・安値／複数の根拠／損切り必須／RR 1:1.5〜1:3 の目安。

推奨仮設定（画面に「※」「仮設定」と出す。もちぽよ公式の機械売買ルールとしては扱わない）：
- 上位足の見方 `htfMode`（新しい仮設定）：判定できる上位足がすべて同じ向き（もちぽよの既定）／4時間足を優先（一般 FX の既定）／両方が同じ向き（厳しめ）。履歴不足は「判定不可」でレンジとは別
- コスト：スプレッド 0.6pips・入口の滑り 0.1・損切り（成行）の滑り 0.3・手数料 0 円（架空の相場の仮定）。ストレスの例：損切りを ATR×1・×2 越えて約定
- 待ち 540分・保有 1440分（v9.0 の 15分足 36 本・96 本と同じ長さを、分に直した）
- 上級の管理の採点の重み（計画 3 点・計画と実際 6 点・早めの決済の理由 6 点）、A の B（条件がそろってから）の条件＝推奨仮設定の evaluateEntry、B の点（誤り 1 つ 10 点・言いがかり −5 点）、D の判定（A／B／C の境目）、1 群あたりの問題数の上限 5

数値の定義（`TradeCore.DEFINITIONS` と同じ）：
- gross pips＝エントリーの中値 → 決済の中値。net pips＝約定価格どうし。cost＝gross − net（入口・出口のスプレッドの半分ずつ＋入口の滑り＋決済の滑り。窓で損切りを越えた分は `gapSlippagePips` に別に記録し、cost に二重に入れない）
- R＝net pips ÷ 当初のリスク（約定価格 → 当初の損切り）。部分決済があるときは、実現した損益の合計 ÷ 当初の口座リスク（分母は当初のまま）
- PF（円）＝勝ちの円の合計 ÷ 負けの円の合計の絶対値。PF（R）＝勝ちの R の合計 ÷ 負けの R の合計の絶対値
- 最大DD：金額の最大と割合の最大を別々に（同じ区間とは限らない）。含み損込みは各取引の MAE を入れた見積もり（ティックの順序は分からない）
- 30連敗：複利 final＝initial×(1−r)^n（1%→73.97%・5%→21.46%）。固定の円の額 final＝initial×(1−n×r)（1%→70%）

未来の情報を使わない決まり：表示・十字線・ZigZag・相手（NPC）の判断・採点の事実・問題の作成・ヒント・思い込みの主張は、判断の時点（asOf：5分足の番号）までの足だけで作る。決済の計算だけが asOf より後の足を使い、結果は振り返りまで出さない。上級の管理では、足を 1 本ずつ進めながら出来事で決済する（先に全部の決済を決めておく作りではない）。

## 4. 前と後の比べ

| 項目 | v9.0（前） | v9.1（後） |
|---|---|---|
| 発注の確認の損失 | 「予想最大損失」（滑り込み） | 「通常約定時の推定損失」＋ストレスの例（ATR×1・×2）＋「損切りは必ず止まる約束ではない」 |
| コスト | net と cost だけ | gross・net・cost の内訳、入口と出口のスプレッドを別に、窓の越えた分、手数料（円）は別 |
| 上位足 | 逆行を「注意だけ」にすると、食い違いの妨げも抜けた | 逆行と食い違いを別々に判定。履歴不足は「判定不可」 |
| PF・DD | PF は R だけ・DD は金額と割合を同じ区間で | PF 円・PF R、DD 金額・割合を別々に、含み損込みの見積もり |
| 記録の上限 300 | 古い記録が消え、始まりの資金が分からない | archive にまとめ、残りの最初の資金を保存（旧セーブは逆算・作り話の過去は足さない） |
| チャート | ＋・－ボタンだけ | 十字線・ドラッグ・ピンチ・ホイール・ダブルタップ・キー・高値安値の指定・線のドラッグ |
| エントリー足 | 問題ごとに決まっていた | 5分足・15分足を選べる（同じ時刻）。進める時間も別に選べる |
| 決済 | エントリー足（15分足など）で判定 | 5分足で判定（同じ時刻・同じ注文なら、選んだ足に関係なく同じ結果） |
| 保有中の管理 | なし（当初のまま） | 上級の管理（設定で ON）：建値・部分決済・トレーリング・早めの決済 |
| Lv8 | 学習用と同じ生成の別 seed・直近 24 件を避けるだけ | 別の生成系列 B・30 問で重複 0・群の上限・中断と再開でも重複なし・試験の間は型と結果を出さない・判定保留 |
| 相手（トレードマスター）の強さ（120 問・腕前 1） | `docs/trading-learning/logs/tm_adv_stats.json` | `docs/trade-advanced/logs/tm_adv_stats_v91.json`（決済を 5分足にしたため数え直した。例：順張り 期待値 +0.02R → −0.07R、万能 +0.08R → +0.08R。判断の点：順張り 85.7 → 84.5・万能 100 → 100） |

# 3D版 開発ロードマップ

正式公開は「3D版が既存2D版と同等以上の機能・品質になり、承認を受けた後」とします。それまでは `feature/3d-remaster` ブランチ・`/3d/` の開発プレビューで進めます。

| Phase | 内容 | 状態 |
|---|---|---|
| 0 | 現状解析・3D移行設計・機能互換チェックリスト・アセット制作リスト・ロードマップ | **完了**（`docs/3d/`） |
| 1 | ポヨ村（屋外＋屋内6か所）の3D化：建物・地形・草木・小物・昼夜・主人公と村人のモデル（アニメーション9種）・自由移動・会話・宝箱・出入り・メニュー／セーブの継承・2D版セーブの取り込み・スマホ操作・画質設定・確認ページ | **技術プロトタイプとして完了**（美術品質は参考画像に未達。詳しくは `Phase1_テスト結果.md`） |
| 1.5 | 実機確認と調整：GPU つき PC・iPhone・Android で fps 計測、画質の自動調整、操作感（速度・カメラ）の調整、主人公の職業別の見た目 | 未着手（実機での確認が必要） |
| 2 | 最初の地域（アルカディア大陸の町・ワールドマップの一部）の3D化。地域ごとの読み込み（ポヨ村と同じ仕組み）、NPC モデルの追加 | 未着手 |
| 3 | 戦闘の3D化：仲間14人・最初の地域のモンスター（系統ごとに高品質の基本形）・攻撃／呪文／被弾の演出。戦闘の計算は2D版の `combat.js` をそのまま使う | 未着手 |
| 4 | 乗り物（船・飛空艇）とフィールドの3D化、ダンジョンの3D化 | 未着手 |
| 5 | 残りの地域（12地域を順番に。**一度に全部は読み込まない**） | 未着手 |
| 6 | 2D版と同等以上の確認（全章の通しプレイ・セーブ互換・性能）→ 承認 → 公開 | 未着手 |

## Phase 1 の次にすぐ必要なこと

1. **実機での fps 計測**（この開発環境は GPU がなく、ソフトウェア描画でしか確認できていないため）。
2. 主人公の見た目を職業（2D版の `hero.sprite`）に合わせる。
3. 美術品質の向上：キャラクターの顔・髪・服のしわ、木の葉の形、石畳の縁石、屋根の苔や汚れ、窓の内側の家具など。

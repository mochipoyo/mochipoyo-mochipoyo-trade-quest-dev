## 2. 一部だけ／未実装（正直に）

- **チャートの場面**：増やしたのは「同じ34のシナリオ（場面の型）の、別のチャートのデータ」136。場面の型（教える内容）そのものは増やしていない。クイズモンスターのチャートの読み取り問題（固定の11問）は変えていない。学習の石碑の「必須の試練」は、これまでどおり決まったチャート（失敗したら同じ場面で復習できるように）
- **IQテスト**：遊びの頭の体操。本物の知能検査（専門家が行う、決まったやり方の検査）ではない。数字は目安にもならない（画面・館の張り紙・係員の説明でもそう伝える）
- **能力の道具**：上がる数は 1〜4（ご依頼のとおり）。最大HP・最大MP にも 1〜4 なので、後半ではほとんど差を感じないかもしれない
- **個性的な町の人**：3D では共通の人のモデル（村人・学者・船乗りなど）で、色は 2D だけ。仲間にはならない・物語やクエストは持たない（話すだけ）
- **城の家畜**：城（屋内）には犬と猫だけ。家畜（馬など）は城下町に置いた
- **地区の型**：同じ型を使う町（リヴェルと王都、カリオンとノード、港町とアルナ、消えた村と廃墟の街、砂都と鏡の市場、星見と前線基地）は、左右を反対にしたり大きさが違ったりするが、似た並びになる。地区の部屋（屋内）の形は v7.2 のまま
- **v7.2 のセーブ**：v7.2 で足した新しい地区の店（花屋・パン屋など）の中には、地区の並びが変わって無くなった部屋がある（20部屋）。その部屋の中でセーブしていた場合は、その町の塔の前から始まる（js/rpg/world.js）
